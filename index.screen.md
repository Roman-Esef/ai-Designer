# Хаб проектов

## 1. Назначение

Служебная стартовая страница рабочего пространства: одна точка входа в
документацию дизайн-системы, в проекты и в концепты. Не экран продукта — в
разработку не уходит.

| Колонка | Что в ней | Папка |
|---|---|---|
| Дизайн-система | документация ДС | `DS-IBP/` |
| Проекты | файлы, соответствующие настоящей системе; строго на компонентах ДС | `Projects/` |
| Концепты | концепты на ДС; кастомные решения — только если ТЗ прямо их просит | `Concepts/` |

**Роль пользователя:** дизайнер, ведущий проекты и концепты на ДС.

## 2. Навигация

| Уровень | Текст | Ссылка |
|---|---|---|
| 1 (текущий) | Хаб проектов | — |

Пункт бокового меню в состоянии `nav__item--selected`: «Хаб проектов».

| Блок меню | Пункты |
|---|---|
| — | Хаб проектов (`main-page`) |
| Дизайн-система | записи реестра `group: 'ds'` |
| Проекты | записи реестра `group: 'projects'` |
| Концепты | записи реестра `group: 'concepts'` |

Футер панели — `IBPHome.footerHTML` из каталога ДС: пользователь каталога,
вторая строка «Хаб проектов». Строка пользователя ведёт на эту же страницу
(`href="index.html"`, `aria-current="page"`): в экранах проектов и концептов она
ведёт сюда, а на хабе отмечает текущую точку. Кнопка выхода — элемент макета,
действия у неё нет.

**Обратные переходы на хаб:**

| Откуда | Как |
|---|---|
| Экран проекта или концепта | `<a class="nav__user">` в футере меню, `aria-label="Хаб проектов"`, относительный путь до корневого `index.html`. В продукте эта строка ведёт в личный кабинет, подмена действует только в макетах |
| Документация ДС | закреплённый низ левой панели `.ds-nav__footer` — «Хаб проектов» (`DS-IBP/scripts/ds-nav.js`) |

## 3. Шапка страницы (PageHeader)

Шапки нет — раскладка стартовой страницы (Layout).

## 4. Структура контента

Контентная область — `.home-wrap` с фоновой иллюстрацией, внутри `.grid12`
(12 колонок, зазор 16px; сетка стартовой страницы, Layout).

| № | Блок | Компонент | Колонок из 12 | Содержимое |
|---|---|---|---|---|
| 1 | Дизайн-система | Tile (заголовок M, без действий) | 3 (`col-3`), ≤1700px — 6, ≤900px — 12 | `.entity-list` со строками Entity M `--interactive` из записей `group: 'ds'` |
| 2 | Проекты | то же | то же | записи `group: 'projects'` |
| 3 | Концепты | то же | то же | записи `group: 'concepts'` |

Группа без записей не выводится. Вертикальный скролл — у контентной области,
крошки залипают. Горизонтального скролла нет.

**Строка (Entity M):**

| Слот | Значение | Класс |
|---|---|---|
| Контейнер строк | список, зазор 16px | `.entity-list` |
| Корень | ссылка на стартовую страницу (`href` реестра) | `a.entity.entity--interactive` |
| Ведущий | глиф `icon` реестра | `.entity__lead > .entity__icon` |
| Header | папка записи (`root`; у ДС — папка стартовой страницы) | `.entity__header` |
| Label | название (`title`), усечение в строку + тултип | `.entity__label--truncate` + `data-tooltip-truncated="only"` |
| Subheaders | описание (`desc`), одна строка | `.entity__subs--single > .entity__subs-list` |

## 5. Поведение

| Триггер | Результат |
|---|---|
| Клик по строке | переход на стартовую страницу записи |
| Клик по пункту меню записи | то же |
| Наведение на строку | фон `--bgtable-row-hover`; подложка стыкуется с соседней строкой, не накрывая её (`.entity-list`) |
| Бургер / пин панели | rail ↔ drawer ↔ fixed (рантайм NavPanel) |
| Рабочая область ≤ 1700px | колонки 3+3+3 → 6+6 / 6 |
| Рабочая область ≤ 900px | колонки в одну (12) |
| Новая запись в `hub.js` | строка и пункт меню появляются без правки страницы |

## 6. Данные

Источник — `hub.js` в корне, `window.IBPHub`, одна запись на проект или концепт.

| Поле | Тип | Обязательное | Примечание |
|---|---|---|---|
| `id` | строка | да | уникальный ключ |
| `group` | перечисление | да | `ds` · `projects` · `concepts` |
| `title` | строка | да | название строки и пункта меню |
| `desc` | строка | да | описание одной строкой |
| `href` | строка | да | стартовая страница, путь от корня |
| `root` | строка / null | да для `projects` и `concepts` | папка записи от корня, внутри `Projects/` или `Concepts/` |
| `icon` | строка | да | имя глифа из `DS-IBP/specs/Icons.md` |

Полноту реестра и обратные переходы проверяет сторож
`.opencode/skills/screen-review/tooling/projects-hub.mjs` (шаг `projects` гейта).

## 9. Доступность

- `<main>` для контентной области, `<nav aria-label="Хлебные крошки">`,
  `<nav aria-label="Главное меню">`;
- заголовки колонок — `h2`; `h1` нет, как на стартовой странице;
- строка — настоящая ссылка: фокус с клавиатуры и Enter без скрипта;
- ведущая иконка `aria-hidden`, смысл несёт Label.
