# Сделки

## 0. Модульная структура (пилот — что проверяем)

Страница собрана из отдельных файлов по образцу файловой архитектуры
разработчиков (папка страницы + отдельные файлы модалок и таблиц). Агент,
переводящий макет в код, читает эту спец-файл вместе с файлами ниже и мапит их
на свои компоненты один к одному.

| Файл | Что содержит | Аналог у разработчиков |
|---|---|---|
| `Projects/test/post/index.html` | каркас страницы: каркас Layout, навигация, крошки, PageHeader + метки `<ds-include src="…">` | `pages/Deals/index.tsx` (импорты) |
| `Projects/test/post/tables/DealsTable.html` | таблица-реестр целиком (тулбар, тело, пагинация) | `tables/DealsTable.tsx` |
| `Projects/test/post/modals/Filter.html` | модалка фильтра `.tfm` (`#filter-scrim`) | `modals/DealsFilterModal.tsx` |
| `Projects/test/post/modals/EditDeal.html` | форма «Редактирование сделки» (`#deal-form-scrim`) | `modals/DealFormModal.tsx` |
| `Projects/test/post/modals/DeleteConfirm.html` | подтверждение удаления (`#delete-scrim`) | `modals/DeleteConfirmModal.tsx` |
| `Projects/test/post/index.preview.html` | **собранный** экран — результат `assemble.mjs`, открывается двойным кликом | бандл |

Сборка: `node Projects/test/post/assemble.mjs` (index.html + фрагменты →
index.preview.html). Проверка собранного файла: `node
Projects/test/post/verify.mjs`.

Связь между файлами — по `id` скримов: триггеры в таблице и шапке страницы
ссылаются `data-modal="filter-scrim"`, `data-modal="deal-form-scrim"`,
`data-modal="delete-scrim"`; сами скримы лежат в файлах `modals/*.html`. `id`
обязаны быть уникальны в пределах всего экрана (проверяет `verify.mjs`).

## 1. Назначение

Демо-реестр сделок направления Post (operations, финансисты). Пилот собран не
под конкретное ТЗ, а для проверки модульной структуры: страница ↔ отдельные
файлы модалок и таблиц. Контент правдоподобен по форме, но предметные статусы
и перечни — **демо-допущение**, а не выверенный справочник продукта.

**Роль пользователя:** аналитик / финансист направления Post

## 5. Таблица «Сделки» (`tables/DealsTable.html`)

**Тулбар:** заголовок «Сделки», счётчик «128», TableFilter (кнопка «Фильтр» +
чип «Применено: 2»), кнопка настройки колонок (`data-table-settings` — модалку
колонок строит рантайм, файл для неё не нужен).

| Ключ | Заголовок | Тип | Ширина | Выравн. | Сортировка | В фильтре |
|---|---|---|---|---|---|---|
| `select` | — | чекбокс | 44px | центр | нет | нет |
| `counterparty` | Контрагент | текст | 2fr | слева | да | да |
| `product` | Продукт | текст | 1.3fr | слева | да | да |
| `amount` | Сумма, RUB | число | 150px | справа | да, активна по убыванию (строки стоят по убыванию) | нет |
| `status` | Статус | Chip | 130px | слева | да | да |
| `date` | Дата сделки | дата | 120px | слева | да | да, диапазон дат |
| `actions` | Действия | IconButton ×2 | 96px | центр | нет | нет |

Значения: суммы — `1 240 500,00`; даты на экране — `ДД.ММ.ГГГГ`,
машиночитаемое для сортировки — ISO (`data-sort-value`). Кнопки действий
обёрнуты в `<span class="tc__controls">` (не `<div>` — счётчик разделителей
строки в статической проверке учитывает только `<div>`-ячейки).

**Выбор строк:** есть (колонка чекбоксов). Панель массовых действий в макете
не показана (строки не выбраны).

**Пагинация:** `data-pagination data-total="128" data-page="1"
data-page-size="50"` — рантайм рисует сам.

## 6. Поведение

| Триггер | Результат |
|---|---|
| Клик по кнопке сортировки в шапке | цикл: нет → по возрастанию → по убыванию → нет |
| Клик «Фильтр» | открывается `#filter-scrim` (`.modal--w6 .tfm`) |
| Клик «Создать сделку» / «Изменить» в строке | открывается `#deal-form-scrim` (`.modal--w6`, форма) |
| Клик «Удалить» в строке | открывается `#delete-scrim` (`.modal--w3`, подтверждение) |
| Перетаскивание границы шапки колонки | изменение ширины колонки |
| Сортировка по клику | перестановка строк в макете (`data-sort-rows`), в проде — `sort` на бэкенд |

Фильтрация строк, пересчёт пагинации, сохранение — модель данных потребителя,
в макете не реализуются (вёрстка состояния + правила выше).

## 12. Доступность

- единственный `h1`; `<main class="screen__content">`;
- сортировка объявлена `aria-sort`, у всех кнопок-иконок есть `aria-label`;
- скримы модалок закрыты атрибутом `hidden` (открывает рантайм `ds-modal.js`);
- модалки `role="dialog"` + `aria-modal` + `aria-labelledby`.
