# Projects — проекты на дизайн-системе IBP

Здесь живут проекты, собранные на компонентах дизайн-системы из `../DS-IBP/`.

## Структура

- `Projects/<ИмяПроекта>/components/` — локальные компоненты проекта (тайлы, виджеты, специфичные для направления).
- Экраны, собранные агентом `ai-designer`, складываются в `Projects/test/` (плоско, без подпапок): `<Имя>.html` + `<Имя>.screen.md`.

## Соглашения

- Компоненты берутся только из дизайн-системы `DS-IBP/`. Нет нужного — не изобретать, а спросить или оформить как локальный компонент проекта.
- Локальные компоненты подключаются к агенту отдельным скиллом, без правки самого агента.
- Экраны подключают `../../DS-IBP/ds.css` и `../../DS-IBP/scripts/ds.js` — пути от `Projects/test/`.
