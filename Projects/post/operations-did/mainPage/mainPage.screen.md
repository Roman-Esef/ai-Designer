# Главная страница

## 1. Назначение

Стартовая главная страница продукта с навигационными тайлами (NavTile):
точка входа в разделы. Набор групп тайлов и пунктов меню определяется
**ролью** пользователя; на экране — роль «Финансист ДИД». Все крошки других
страниц ведут на эту страницу первой ссылкой «Главная».

**Роль пользователя:** финансист ДИД (4 группы: Текущий портфель ДИД, Отчёты,
Клиенты и задачи, Администрирование).

## 2. Навигация

| Уровень | Текст | Ссылка |
|---|---|---|
| 1 (текущий) | Главная | — |

Крошки на самой главной — единственная ссылка «Главная» (намеренно; решение
пользователя). Пункт меню «Главная» (`main-page`) — текущий
(`nav__item--selected` + `aria-current="page"`).

## 3. Источник данных — единый каталог

Меню панели и тайлы главной строятся из одного файла
`DS-IBP/scripts/ibp-home.js` (`window.IBPHome`):

- `IBPHome.itemsFor(role)` — группы меню роли (с по-пунктной доступностью,
  partial: у роли «Финансист ДИД» в «Администрировании» только «Администрирование»,
  без «Администратор ЦКП»; Origination и Pipeline не входят);
- `IBPHome.tileHTML(item)` — разметка NavTile (обычный `<a>` или «со ссылками»);
- `item.tile === null` — пункт меню без тайла (исключение «Поиск клиентов в ЕПК»);
- `item.tile.links` — тайл со ссылками («Отчёты для Рисков»: Коды RWA, Расчет RWA,
  Расчет ОВП).

Изменение каталога подхватывается экраном, панелью и страницей NavTile без
правки экрана.

## 4. Раскладка (1920, референс)

- Каркас Layout: `nav-layout` → панель `.nav.nav--drawer` + `.screen` →
  `.crumbs` (44px, крошка «Главная» — текущая страница) → `main.screen__content`
  (поля 24px).
- 12-колоночная сетка `.home-groups` (гэп 16px): **группа = колонка `span 3`**,
  4 группы в ряд; пятая и далее переносятся под первую/вторую.
- Внутри колонки `.home-group` — заголовок группы (h5 Strong) + тайлы
  (NavTile, тянутся на ширину колонки) с вертикальным гэпом 16px.
- Перестроение: `@container screen (max-width: 1700px)` → колонки `span 6`,
  `900px` → `span 12`. 4 колонки — только при рабочей области >1700px
  (rail-1920 и drawer-1920: область 1864px); при закреплении панели
  (fixed-1920: область 1648px) — 2 колонки.
- Фоновая иллюстрация `background-illustration.svg` (1066×777) — только на
  главной, `background-size: cover` за контентом (`opacity .6`).

## 5. Поведение

- Клик по обычному тайлу — переход на страницу раздела (вся плитка — ссылка).
- Тайлы со ссылками («Отчёты 1C/Navision», «Корпоративные запросы», «Отчёты для
  Рисков») — переход по названию или по ссылке; фон плитки не кликабелен
  (правило NavTile).
- Кнопка «выход» в футере панели открывает **модалку смены роли**; выбор роли
  перерисовывает и меню панели, и тайлы главной (роль хранится в `role`
  экранного скрипта; сейчас доступна одна роль — «Финансист ДИД»).
- Строка пользователя в футере — ссылка на личный кабинет; должность —
  заглушка по текущей роли.

Соответствие меню ↔ тайлы: каждый пункт меню роли имеет тайл, кроме
«Поиск клиентов в ЕПК» (исключение — есть в меню, тайла нет). Пункт меню без
тайла на главной — ошибка (валидация закрепляется при развитии главной).

## 7. Правки 01.09.2026 (после приёмки)

1. Сброшен `body { margin: 0 }` (UA-дефолт 8px давал белую рамку по периметру и
   вклад в горизонтальный скролл).
2. Тайлы в колонках тянутся на ширину колонки (`.home-group .ntile
   { width: auto; min-width: 0 }`) — убран горизонтальный скролл и переполнение.
3. Крошка «Главная» — состояние текущей страницы (`crumbs__current`,
   `aria-current="page"`).
4. Иллюстрации загружаются: задан `window.__DS_ROOT = '../../../../DS-IBP/'`.
5. Рефлоу: 4 колонки только при рабочей области >1700px (rail/drawer-1920);
   при закреплении панели — 2 колонки, далее 1.
6. Фоновая иллюстрация: opacity .6.
7. «Отчёты 1C/Navision» и «Корпоративные запросы» стали тайлами со ссылками
   (данные — ibp-home.js).

   позиция взята из предположения).
2. Перестроение на узких экранах (span 6/12) — базовое; финальные
   брейкпоинты уточнить.
3. Роль «Финансист ДИД» — единственная; при добавлении ролей (Origination/
   Pipeline и др.) состав групп/тайлов расширяется в `ibp-home.js`, экран
   подхватывает автоматически.
