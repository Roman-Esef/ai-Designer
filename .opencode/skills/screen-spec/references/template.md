# Реестр сделок

## 1. Назначение

Одно-два предложения: чью задачу решает экран и в какой момент процесса
пользователь на него попадает. Формулировка из ТЗ, не придуманная.

**Роль пользователя:** менеджер сделок, риск-менеджер
**Права:** чтение всех сделок подразделения, редактирование своих

## 4. Структура контента

Контентная область — 12 колонок, зазор 16px, вертикальный зазор блоков 24px.

| № | Блок | Компонент | Колонок из 12 | Содержимое |
|---|---|---|---|---|
| 1 | Сводка по портфелю | Tile ×3 в одном ряду | 4 + 4 + 4 | по 3 показателя ReadOnlyField в каждом |
| 2 | Таблица сделок | Table | 12 | 8 колонок, фильтр, пагинация |

Вертикальный скролл: есть, скроллится контентная область, крошки залипают.
Горизонтального скролла нет.

## 5. Таблица «Сделки»

**Тулбар:** заголовок «Сделки», счётчик записей, TableFilter, кнопка настройки
колонок, кнопка «Добавить».

| Ключ | Заголовок | Тип | Ширина | Выравн. | Сортировка | В фильтре |
|---|---|---|---|---|---|---|
| `select` | — | чекбокс | 44px | центр | нет | нет |
| `counterparty` | Контрагент | текст | 2fr | слева | да, по умолчанию нет | да, автокомплит |
| `product` | Продукт | текст | 1.5fr | слева | да | да, множественный выбор |
| `amount` | Сумма, ₽ | число | 1fr | справа | да, активна по убыванию | да, диапазон |
| `status` | Статус | Chip | 120px | слева | нет | да, множественный выбор |
| `date` | Дата изменения | дата | 140px | слева | да | да, диапазон дат |
| `actions` | Действия | кнопки | 96px | центр | нет | нет |

**Формат значений:** суммы — `1 240 500,00` с неразрывными разрядами;
даты — `ДД.ММ.ГГГГ`; пустое значение — прочерк `—`.

**Статусы колонки `status`:**

| Значение | Chip |
|---|---|
| Черновик | `chip--s` (нейтральный) |
| Активна | `chip--s chip--success` |
| На доработке | `chip--s chip--warning` |
| Отклонена | `chip--s chip--error` |

**Выбор строк:** есть. При выборе появляется панель массовых действий
(`.pgn-bulk`): «Выгрузить», «Удалить». Удаление продублировано в колонке
«Действия» на уровне строки.

**Пагинация:** 50 строк на страницу, переключатель размера страницы, счётчик
диапазона.

## 6. Поведение

| Триггер | Результат |
|---|---|
| Клик по кнопке сортировки в шапке колонки | цикл: нет → по возрастанию → по убыванию → нет; активна максимум одна колонка |
| Перетаскивание правой границы шапки колонки | изменение ширины колонки, минимум 96px |
| Клик «Фильтр» | открывается модальное окно фильтра (`.modal--w6`) |
| Применён фильтр | в баре появляется чип «Применено: N»; крестик чипа сбрасывает фильтр целиком |
| Двойной клик по строке | открывается модальное окно «Редактирование сделки» с данными строки |
| Клик по кнопке «Изменить» в строке | то же окно |
| Выбор одной и более строк | появляется панель массовых действий над пагинацией |
| Прокрутка тела таблицы | шапка таблицы остаётся на месте (липкая) |
| Сужение рабочей области до 1240px | ряд сводки перестраивается 4+4+4 → 6+6+12 |

## 12. Доступность

- `<main>` для контентной области, `<nav aria-label="Хлебные крошки">`,
  `<nav aria-label="Главное меню">`;
- заголовок страницы — единственный `h1`;
- сортировка колонки объявлена через `aria-sort`;
- у всех кнопок-иконок есть `aria-label`;
- порядок в DOM совпадает с порядком чтения;
- контраст — не ниже WCAG AA (обеспечивается токенами ДС).
