# Фикстура-эталон

Файл не описывает продуктовый экран. Он существует ровно затем, чтобы у
`_base.ok.html` был спутник с заполненной YAML-шапкой: без него Б12 давал бы
FAIL на эталоне, а правило, срабатывающее на чистом входе, доказать нельзя.

Спутников у остальных фикстур нет намеренно — они не экраны, и Б12 на них
срабатывает верно. «Ровно один дефект» держится у корпуса **по каждой
проверке**, а не по каждому файлу.
