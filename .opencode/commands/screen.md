Задача: собрать экран по техническому заданию.

Источник ТЗ: $ARGUMENTS

Если аргумент — путь к файлу, прочитай его. Если это описание словами — работай
по нему. Если аргумент пустой — спроси, где взять ТЗ, и остановись.

Запусти маршрут «Собери экран»: разбери ТЗ сам, задай пользователю вопросы по
непонятному одним списком, затем передай работу субагенту `screen-builder`, а
результат — субагенту `screen-reviewer`. Приёмку не пропускай.

Результат — два файла в папке концепта `Concepts/<Имя>/`: `<Имя>.html` и
`<Имя>.screen.md`, плюс запись экрана в `hub.js` (`group: 'concepts'`) — без
неё гейт красный. Концепт собирается строго на ДС, если ТЗ прямо не просит
кастомного решения.

Если приёмка нашла дефекты и они починены — заход закрывается уроком: скилл
`lessons` (`.opencode/skills/lessons/SKILL.md`), запись с полем «Закрепление»,
затем `lessons-cli add --from <черновик>`.

Заход закрывается одной командой `lessons-cli gate`; строку `ВЕРДИКТ:`
показать пользователю. Затем — handoff задачи (`/handoff`).
