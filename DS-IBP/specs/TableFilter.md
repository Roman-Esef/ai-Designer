> Спека для быстрого контекста. Источник истины — CSS-файл и страница компонента. При изменении компонента обновляй эту спеку и блок в specs/_cheatsheet.md.

## Назначение
TableFilter — панель фильтра над таблицей. Кнопка «Фильтр» (Button Outline S) открывает модалку с параметрами фильтрации; применённый фильтр возвращается в бар одним чипом-счётчиком «Применено: N» (Chip Edit M), где N — число применённых параметров. Крестик чипа сбрасывает фильтр целиком; отдельной кнопки сброса в баре нет. Собирается из готовых компонентов ДС; собственный CSS — только раскладка бара.

## Инварианты
- Сброс чипа «Применено: N» (клик по `.chip__remove` или Backspace/Delete на сфокусированном чипе) — общий рантайм `scripts/ds-table-filter.js`: фейд, удаление, всплытие `tfilter:reset` на `.tfilter` — потребитель слушает событие, чтобы очистить параметры. Открытие модалки — `ds-modal.js`; содержимое модалки (секции, пресеты) держит модель данных потребителя, как и колонки/данные у Table — из коробки не даём.
- Ядро — кнопка «Фильтр» + один чип-счётчик «Применено: N»; крестик чипа сбрасывает ВСЕ параметры фильтра целиком, не один.
- Модалка фильтра растёт по контенту до 80vh — высота не фиксируется, скроллится только Modal_Body (правило Modal).
- Legacy-разметка (чиплист параметров + шеврон-аккордеон) — только для ранее собранных экранов, в новых не использовать.

## Диагностика
- «Крестик на чипе снимает только один параметр» → по спеке сбрасывает все параметры сразу
- «Новый экран использует legacy-чиплист» → перейти на актуальную разметку: кнопка + один чип «Применено: N»

## Ключевые правила (из разделов страницы)
- **Использование** — Фильтрация таблицы сразу по нескольким параметрам, когда условие собирается в модалке и сохраняется наборами. Не для фильтра по одному полю (инлайн-поиск / Select в шапке колонки) и не для переключения вьюх (Tab / SegmentControl).
- **Анатомия** — Кнопка «Фильтр» (Button Outline S с ведущей воронкой в `--primary`) и, при активном фильтре, чип «Применено: N» (Chip Edit M) справа от неё. Зазор — 4px. Если есть сохранённые пресеты, одиночная кнопка заменяется на ButtonGroup Split: «Фильтр» + шеврон вниз со списком названий пресетов.
- **Варианты · Состояние бара** — Filtered=No (только кнопка) и Filtered=Yes (кнопка + чип «Применено: N»).
- **Варианты · С сохранёнными пресетами** — Пресетов нет — одиночная кнопка «Фильтр». Есть пресеты — ButtonGroup в варианте Split Button: слева «Фильтр» (модалка), справа шеврон вниз, открывающий ContextMenu с названиями пресетов (цифра справа в пункте — число параметров пресета). Выбор пункта применяет пресет сразу, минуя модалку.
- **Варианты · Чип «Применено»** — Один чип на любое число параметров, меняется только N (tabular-nums, чтобы ширина не дёргалась). Чип не переносится на второй ряд и не обрезается.
- **Размеры** — Кнопка Button Outline S и чип Chip Edit M — оба 32px, высота бара 32px. Зазор между кнопкой и чипом — 4px, единственный отступ внутри бара.
- **Размеры · Радиус скругления** — Своих радиусов бар не задаёт. кнопка (Button Outline S) — 8px · чип (Chip Edit M) — 8px (--radius-control) · бар — 0.
- **Контент** — Чип: «Применено: N», текст фиксирован, категории и значения в баре не перечисляются. N считается по параметрам, не по значениям («ТБ: ЦА, МБ, СРБ» = 1). N=0 — чипа нет. Кнопка «Фильтр» — существительное без счётчика.
- **Поведение · Открытие модалки** — Клик по «Фильтр» открывает Modal w6: Modal_Top (заголовок «Фильтр» + крестик), Modal_Body `--flush` = сетка [nav 232px | контентная область] с двухколоночной формой (`.tfm__grid`, grid 2×minmax(0,1fr), gap 16px; широкое поле — `.tfm__span-2`; диапазоны дат — InputDateRange на всю ширину), Modal_Bottom — слева «Сохранить пресет», справа «Очистить» + «Применить». Высота модалки не фиксирована — контент до 80vh, прокручивается сам Modal_Body (своего скроллера у контентной области нет), навигация `position: sticky`, шапка и подвал получают тень по `.is-scrolled`. «Применить» закрывает модалку и возвращает чип «Применено: N».
- **Поведение · Разделы модалки — якорные ссылки** — Вертикальные табы (Tab M vertical) прижаты вплотную к левой границе модалки (у навигации нет бокового паддинга, рельс и индикатор совпадают с краем Modal_Body). Табы не переключают вьюхи: контентная область содержит все разделы подряд и прокручивается, клик доводит панель до раздела, при прокрутке активным становится верхний видимый раздел (`aria-current="true"`, не `role="tablist"`). Бейдж таба — число заполненных параметров раздела.
- **Поведение · Выбор пресета из бара** — Шеврон открывает меню под группой (зазор 6px, выравнивание по левому краю): `aria-expanded` на шевроне, `role="menu"`/`menuitem` в списке. Выбор пункта применяет пресет и даёт чип «Применено: N» по числу его параметров; закрытие — клик вне, Esc или выбор пункта; ↑/↓ водят по пунктам.
- **Поведение · Скролл страницы под скримом** — Пока модалка открыта, страница за скримом не прокручивается: на `body` ставится `overflow: hidden`, ширина исчезнувшего скроллбара компенсируется правым паддингом; содержимое за скримом получает `inert`/`aria-hidden`, фокус заперт внутри (focus trap), при открытии уходит на первое поле тела, при закрытии возвращается на инициатор. Замки считаются — вложенный диалог берёт свой, скролл возвращается после закрытия последнего слоя.
- **Поведение · Счётчик** — После «Применить» N пересчитывается; параметр, у которого сняли все значения, из счёта уходит.
- **Поведение · Сброс** — Крестик чипа (или Backspace/Delete на сфокусированном чипе) сбрасывает фильтр целиком: параметры очищаются, таблица перезапрашивается, чип исчезает. Точечное снятие одного параметра — только в модалке.
- **Поведение · Сохранённые пресеты** — Кнопка «Сохранить пресет» в подвале открывает вложенный диалог «Сохранить пресет» (w3, одно поле). Пресеты (до 5) живут в разделе «Сохранённые пресеты»: применить, заменить (вложенный confirm при занятом имени), удалить (вложенный confirm). Карточка пресета раскрывается шевроном-аккордеоном (IconButton Neutral S) и показывает таблицу «Параметр — значение»; корзина — IconButton Neutral S. Пустой список — плейсхолдер.
- **Состояния** — Наследуются от Button и Chip. Отдельно у бара: заблокированность (`.tfilter--disabled`, pointer-events:none + opacity).
- **Доступность** — Бар `role="group"` + `aria-label="Фильтр таблицы"`. Кнопка «Фильтр» — `aria-haspopup="dialog"` + `aria-expanded`. Чип фокусируем, крестик — «Сбросить все фильтры», Backspace/Delete сбрасывает. Навигация модалки — `<nav>` с `aria-current` на активном разделе; шеврон пресета — `aria-expanded` + `aria-controls`.
- **Типографика** — Собственной нет: подпись кнопки — токены Button (S); текст чипа — SB Sans Text Body M (Chip M), N — tabular-nums.
- **Цвета** — Только семантические токены. Собственное — тонирование ведущей воронки кнопки в `--primary`; остальное из Button и Chip. Чип — рампа StSystem (фон `--st-system-light`, обводка `--st-system-midlight`).

## Для разработчиков (выжимка)

### Точные размеры (redline)
Таблица рендерится на странице через getComputedStyle на живом баре. Значения — токены в `styles/table-filter.css`, `styles/chip.css`, `styles/button.css`: зазор бара, высота/паддинги/радиус кнопки и чипа, типографика чипа.

### Разметка · HTML (эталонная реализация ДС)

```
<!-- фильтр не применён -->
<div class="tfilter" role="group" aria-label="Фильтр таблицы">
  <button class="btn btn--outline btn--s tfilter__open" aria-haspopup="dialog" aria-expanded="false"><i data-icon="filter"></i><span class="btn__label">Фильтр</span></button>
</div>

<!-- применён: кнопка + один чип-счётчик -->
<div class="tfilter" role="group" aria-label="Фильтр таблицы">
  <button class="btn btn--outline btn--s tfilter__open" aria-haspopup="dialog" aria-expanded="false"><i data-icon="filter"></i><span class="btn__label">Фильтр</span></button>
  <span class="chip chip--edit chip--m tfilter__applied" tabindex="0"><span class="chip__label">Применено: 3</span><span class="chip__remove" role="button" aria-label="Сбросить все фильтры">…✕…</span></span>
</div>

<!-- модалка: nav вплотную к левой границе, контент прокручивается -->
<div class="modal modal--w6 tfm" role="dialog" aria-modal="true" aria-labelledby="tfm-title">
  <header class="modal__head">…«Фильтр» + крестик…</header>
  <div class="modal__body modal__body--flush"><div class="tfm__body">
    <nav class="tabs tabs--vert tfm__nav" aria-label="Разделы фильтра">
      <button class="tab tab--m tab--vert tab--selected" aria-current="true" data-target="tfm-sec-general"><span class="tab__label">Общая информация</span><span class="tab__badge">3</span></button>
      …
    </nav>
    <div class="tfm__panel"><section class="tfm__sec" id="tfm-sec-general">…</section>…</div>
  </div></div>
  <footer class="modal__foot">…«Сохранить пресет» | «Очистить» + «Применить»…</footer>
</div>
```

### Поведение · псевдокод (framework-agnostic)

```
// 1. Бар: params.length === 0 → только кнопка «Фильтр»;
//    ≥1 → рядом чип «Применено: {params.length}», зазор 4px. Кнопки сброса нет.

// 2. Применение (Применить в модалке): params = поля с непустыми значениями →
//    записать в состояние таблицы, перезапросить данные, закрыть модалку, N = params.length.

// 3. Сброс: крестик чипа ИЛИ Backspace/Delete на чипе → params = [], перезапрос,
//    чип убрать, фокус на кнопку «Фильтр».

// 4. Разделы модалки = якорные ссылки:
onNavClick(section): active = section.id; panel.scrollTo({top: section.offsetTop - 16, behavior:'smooth'});
                     подавить scroll-spy на время анимации (~900мс или до scrollend)
onPanelScroll():     если достигнут низ (scrollTop >= scrollHeight - clientHeight - 2) → последняя секция;
                     иначе active = последняя секция с offsetTop - panel.scrollTop <= 48
badge(tab) = число заполненных параметров раздела (0 → бейджа нет)

// 5. Пресеты (до 5): save(name) — вложенный диалог w3 с одним полем; имя занято →
//    confirm «Заменить пресет?»; apply → см. п.2; remove → confirm «Удалить пресет?».
//    Карточка: шеврон-аккордеон раскрывает таблицу «Параметр — значение». Пусто → плейсхолдер.
```

### Справочник классов и атрибутов

| Класс/атрибут | Назначение |
|---|---|
| `.tfilter` | Корень-бар: flex, wrap, gap 4px; `role="group"` |
| `.tfilter--disabled` | Бар недоступен целиком (pointer-events:none + opacity) |
| `.tfilter__open` | Кнопка вызова модалки (Button Outline S, `aria-haspopup="dialog"`, `aria-expanded`) |
| `.tfilter__applied` | Чип-счётчик «Применено: N» (Chip Edit M); крестик сбрасывает все параметры |
| `.tfilter__split` / `.tfilter__presets` / `.tfilter__menu` | ButtonGroup Split при наличии пресетов: `.menu-anchor`-обёртка, шеврон (`aria-haspopup="menu"`), выпадающий список названий (`.menu.menu--floating`, top 100%+6px, left 0) |
| `.tfm__grid` / `.tfm__span-2` | Двухколоночная сетка формы / поле на всю ширину |
| `.tfm__panel` | Контентная область: только паддинги и поток разделов, без своего `overflow` — прокручивается `.modal__body` |
| `.tfm` | Модификатор модалки фильтра (контент прокручивается внутри `.tfm__panel`) |
| `.tfm__body` / `.tfm__nav` / `.tfm__panel` / `.tfm__sec` | Сетка модалки: навигация вплотную к левому краю, прокручиваемая контентная область, разделы-якоря |
| `.preset-item` / `.preset-row` / `.preset-item__body` / `.preset-params` | Карточка пресета: шапка, раскрываемое тело, таблица «Параметр — значение» |
| LEGACY: `.tfilter__trigger`, `.tfilter__chips`, `.tfilter__tail`, `.tfilter__more`, `.tfilter__toggle`, `.tfilter--collapsed` | Старая модель (чиплист параметров + «+N» + аккордеон). Правила остались только ради ранее собранных экранов-мокапов, в новых не использовать |
