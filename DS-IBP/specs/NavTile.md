# NavTile — навигационная плитка

Плитка главной страницы платформы: слева название раздела и описание, справа иллюстрация фиксированного размера 195×140, прижатая к правому краю и центрированная по вертикали. Клик — переход на страницу раздела. Не дашборд: данных и графиков не показывает.

## Инварианты
- Плитка не сжимается меньше `min-width:400px` — на более узких контейнерах не использовать.
- Вариант «со ссылками» — контейнер `<div>`, не `<a>` (вложенная ссылка в ссылку недопустима); кликабелен только заголовок.
- Иллюстрация фиксирована 195×140, прижата к правому краю и центрирована по вертикали — при росте тайла остаётся по центру.
- Иллюстрация — фон (z-index 0), текст (заголовок/описание/ссылки) — поверх (z-index 1): при сужении тайла текст не уходит под картинку.
- Заголовок — одна строка эллипсисом; описание — клэмп 2 строки, не больше.

## Диагностика
- «Текст наезжает на иллюстрацию при сужении» → не опускать ширину контейнера ниже `min-width:400px`
- «В варианте со ссылками кликабельна вся плитка» → контейнер должен быть `<div>`, кликабелен только `.ntile__title-link`

## Варианты
- **Базовая** — вся плитка одна ссылка: `<a class="ntile" href="…">`.
- **Со ссылками** — контейнер `<div>` (не ссылка: `<a>` в `<a>` недопустимо); на раздел ведёт название `.ntile__title-link`, ниже до 4 ссылок подразделов `.link--accent .link--m`, идут сразу за описанием (не прижаты к низу). Hover-состояний у контейнера нет.

## Каталог тайлов (главная страница)
Полный список тайлов по группам — единый источник `scripts/ibp-home.js` (`window.IBPHome`); витрина — раздел «Варианты → Каталог тайлов» на странице. Тайл = объект `item` с полями меню (label/icon/badge) и тайла (title/desc/illu/links). Пункт меню без тайла — `tile: null` (исключение «Поиск клиентов в ЕПК»). Роли выбирают группы из каталога; экраны главной и демо NavPanel берут данные отсюда — изменение в одном месте подхватывается всеми.

## Размер и сетка
По умолчанию (вне сетки) 442×190px, минимальная ширина плитки 400px (не сжимается меньше). Внутри `.ntile-grid` — `repeat(auto-fill, minmax(400px, 1fr))`, gap 16px по умолчанию; плитки, не помещающиеся в ряд, переносятся на следующий автоматически (без брейкпоинтов/контейнерных запросов). Мин. высота 190px; выше плитка растёт только под свой контент (в ряду НЕ выравнивается по высоте — `align-items: start`). Паддинг 32px (справа — фиксированные 160px под иллюстрацию, чуть меньше её ширины — текст ложится поверх, картинка не перекрывает текст), радиус `--radius-control` (8px). Высота считается с учётом паддингов — `box-sizing: border-box` (минимальная высота 190px — это полная высота плитки, включая паддинги).

## Состояния (базовая)
- Default: фон `--bg-tile`, рамка 1px `--border-light`
- Hover (`.is-hover`): рамка `--border-primary` + `--elevation-2`
- Focus (`.is-focus`): outline 2px `--primary`, offset 2px
- Disabled (`.is-disabled` / `aria-disabled="true"`): текст `--text-inactive`, иллюстрация grayscale + opacity .4, pointer-events none, без href

## Контент
Название — существительное 1–3 слова (H4 Strong); описание 1–2 строки Body M `--text-secondary`; ссылок ≤4 (обрезать на данных); иллюстрация из библиотеки Illustrations, `aria-hidden="true"`.

## DOM
```
<!-- базовая -->
<a class="ntile" href="/deals">
  <span class="illu ntile__illu" data-illu="deals" aria-hidden="true"></span>
  <h3 class="ntile__title">Сделки</h3>
  <p class="ntile__desc">Кредитные линии, договоры и график платежей</p>
</a>

<!-- со ссылками -->
<div class="ntile">
  <span class="illu ntile__illu" data-illu="reports" aria-hidden="true"></span>
  <a class="ntile__title-link" href="/reports"><h3 class="ntile__title">Отчётность</h3></a>
  <p class="ntile__desc">Формы, выгрузки и регламентные отчёты</p>
  <nav class="ntile__links" aria-label="Подразделы">
    <a class="link link--accent link--m" href="/reports/reg">Регламентные</a>
    <a class="link link--accent link--m" href="/reports/export">Выгрузки</a>
  </nav>
</div>

<!-- сетка главной -->
<div class="ntile-grid"> …плитки… </div>
```

## Классы
| Класс | Назначение |
|---|---|
| .ntile | Корень (a — базовая, div — со ссылками) |
| .ntile__illu | Слот иллюстрации 195×140, absolute, прижат к правому краю, центрирован по вертикали |
| .ntile__title / .ntile__desc | Название H4 Strong / описание Body M |
| .ntile__title-link | Ссылка-обёртка названия (только --links) |
| .ntile__links | Колонка ссылок, gap 8px, сразу за описанием |
| .is-hover / .is-pressed / .is-focus / .is-disabled | Форс-состояния для документации; disabled — и для продакшена |

- **Размеры · Радиус скругления** — Один размер, радиус не меняется при hover и фокусе. тайл — 8px (--radius-control) · фокус-обводка ссылки-заголовка — 4px (--radius-xs).
