## Назначение
Drawer — панель деталей у правого края экрана поверх страницы. Отвечает на вопрос «что внутри вот этого объекта из списка», не уводя со списка: доска, реестр или дерево остаются на месте, и у объекта есть «следующий». Открывается по клику на элемент списка, закрывается крестиком, Esc или кликом мимо.

## Инварианты
- Слой у Drawer и Modal **общий** — `scripts/ds-modal.js`. Drawer не заводит своего скрима, focus trap, блокировки прокрутки и стека слоёв; своё у него только геометрия и анатомия шапки. Второй экземпляр логики слоя расходится с первым на первой же правке.
- Скрим панели несёт **оба** класса: `.modal-scrim` (тон, z-index, клик мимо) и `.drawer-scrim` (снимает охранное поле, прижимает панель к краю). Без второго панель встанет по центру и перестанет быть панелью.
- Сторона одна — правая. Левый край занят NavPanel, и панель, выезжающая из-под навигации, конкурирует с ней за один жест и одну зону внимания.
- Тело (`.drawer__body`) — единственная прокручиваемая зона; шапка и подвал закреплены. Панель во всю высоту экрана: `max-height` у неё нет, в отличие от Modal.
- Подвал необязателен: панель просмотра закрывается крестиком. Подвал заводится только там, где есть что подтверждать.

## Ключевые правила (из разделов страницы)
- **Использование** — Drawer, когда пользователь остаётся в списке и будет открывать соседние объекты подряд (карточка на доске, строка реестра). Modal, когда задачу надо закончить или бросить (форма, подтверждение, мастер). Отдельная страница, когда у объекта своя навигация и свой URL, на который ссылаются.
- **Анатомия** — Шапка: путь (`.drawer__path`) + заголовок + действия + крестик. Опциональный Alert во всю ширину. Тело: секции `.drawer__sec` (заголовок секции + опциональное действие справа + сетка пар «подпись — значение»). Опциональный подвал: левая и правая группы кнопок.
- **Варианты** — По ширине: w3 442 · w4 595 (дефолт) · w5 747 · w6 900. По подвалу: с подвалом / без. По шапке: с путём / без. По монтированию: слой (`.drawer-scrim`) / встроенная (`.drawer--inline`, только витрины и превью).
- **Размеры** — Шкала ширины общая с Modal (шаг = число колонок сетки экрана). Высота — всегда 100% вьюпорта. Отступы: по горизонтали 24, шапка 20 сверху/снизу и 20 справа, тело 20 сверху/снизу, подвал 16.
- **Контент** — Заголовок переносится (`text-wrap: pretty`), не обрезается: имя сделки длиннее строки — норма. Путь — крошка «колонка → идентификатор», обязателен, когда панель открыта из списка. Пары «подпись — значение» — ReadOnlyField, в две колонки; одна колонка (`--1col`), когда значения длинные.
- **Поведение** — Выезд справа 200мс, `prefers-reduced-motion` его снимает. Закрытие: крестик, `[data-modal-close]`, Esc, клик мимо. `data-drawer-guarded` на триггере — клик мимо не закрывает (панель с несохранённой формой). Вложенный слой (`data-modal-nested`) открывается поверх панели, не закрывая её. Ниже 640px панель занимает всю ширину.
- **Состояния** — Скрыта (`hidden` на скриме) · открыта · шапка и подвал с тенью при прокрутке тела (`.is-scrolled`, ставит `DSModal.wireScroll`).
- **Доступность** — `role="dialog"` + `aria-modal="true"` на `.drawer`, `aria-labelledby` на заголовок. Триггер получает `aria-haspopup="dialog"` и `aria-controls` — их ставит рантайм. Focus trap, возврат фокуса на триггер и `inert` фона — от `ds-modal.js`. Крестику нужен `aria-label`.
- **Типографика** — Заголовок `--type-h5-strong` (у Modal — h4-strong: панель уже, и её заголовок соседствует с путём). Путь `--type-body-xs`. Заголовок секции `--type-body-s-strong`. Тело `--type-body-m`.
- **Цвета** — Поверхность `--bg-popup`, тень `--shadow-modal-form`, разделители `--border-light`, путь `--text-inactive`, заголовки `--text-primary`. Скрим — `--modal-scrim`.

## Диагностика
- «Панель встала по центру экрана с полями по краям» → на скриме нет класса `.drawer-scrim`
- «Панель не открывается по клику, ошибок в консоли нет» → триггер добавлен после загрузки страницы, нужен `DSDrawer.bindAll(scope)` после перерисовки
- «Фокус уходит на страницу под панелью» → подключён `drawer.css`, но не подключён `scripts/ds-modal.js`: слой — его
- «Шапка панели наезжает на содержимое при прокрутке» → прокручивается не `.drawer__body`, а сама панель: у корня стоит лишний `overflow`

## Для разработчиков (выжимка)

### Точные размеры (redline)
Таблица рендерится на странице через getComputedStyle. Точные значения — в `styles/drawer.css`.

### Разметка · HTML (эталонная реализация ДС)

```
<button data-drawer="d1">Открыть</button>

<div class="modal-scrim drawer-scrim" id="d1" hidden>
  <aside class="drawer drawer--w4" role="dialog" aria-modal="true" aria-labelledby="d1-t">
    <header class="drawer__head">
      <div class="drawer__headmain">
        <p class="drawer__path">Заведение<i data-icon="chevron-right"></i>D-1042</p>
        <h2 class="drawer__title" id="d1-t">ООО «ЮгСтрой» — кредитный мезонин</h2>
      </div>
      <div class="drawer__acts">
        <span class="drawer__close"><button class="ibtn ibtn--neutral ibtn--m" aria-label="Закрыть панель" data-modal-close>…✕…</button></span>
      </div>
    </header>
    <div class="drawer__body">
      <section class="drawer__sec">
        <div class="drawer__sechead"><h3 class="drawer__sectitle">Реквизиты</h3>
          <span class="drawer__secact">…кнопка…</span></div>
        <div class="drawer__grid">…ReadOnlyField…</div>
      </section>
    </div>
    <div class="drawer__foot">
      <div class="drawer__foot-left">…</div>
      <div class="drawer__foot-right">…</div>
    </div>
  </aside>
</div>
```

### Поведение · псевдокод (framework-agnostic)

```
клик по [data-drawer="id"]:
    scrim ← getElementById(id)
    scrim.classList += modal-scrim, drawer-scrim   // геометрия обязана быть панельной
    DSModal.open(scrim, { returnFocus: триггер, guarded: data-drawer-guarded })
        → портал в body, снять hidden, lockPage (inert фона + блок прокрутки),
          wireScroll (тени шапки/подвала), фокус на первый элемент тела

Esc | крестик | [data-modal-close] | клик по скриму (если не guarded):
    DSModal.closeTop() → hidden обратно, unlockPage, фокус на триггер
```

### Справочник классов и атрибутов

| Класс/атрибут | Назначение |
|---|---|
| `.drawer-scrim` | модификатор скрима: панель прижата к правому краю, охранного поля нет |
| `.drawer` | корень панели |
| `.drawer--w3` / `--w4` / `--w5` / `--w6` | ширина по шкале колонок (442 / 595 / 747 / 900) |
| `.drawer--inline` | встроенная в статичный контейнер — витрины и превью |
| `.drawer__head` · `__headmain` · `__path` · `__title` · `__acts` · `__close` | шапка |
| `.drawer__alert` | зона Alert между шапкой и телом |
| `.drawer__body` · `__body--flush` | прокручиваемое тело |
| `.drawer__sec` · `__sechead` · `__sectitle` · `__secact` | секция тела |
| `.drawer__grid` · `--1col` · `.drawer__grid-full` | сетка пар «подпись — значение» |
| `.drawer__foot` · `__foot-left` · `__foot-right` | подвал |
| `.is-scrolled` | тень у шапки/подвала при прокрутке тела (ставит `DSModal.wireScroll`) |
| `data-drawer="id"` | триггер: id скрима панели |
| `data-drawer-guarded` | клик мимо панели не закрывает |
| `data-modal-close` | любой элемент-закрывашка внутри панели |
