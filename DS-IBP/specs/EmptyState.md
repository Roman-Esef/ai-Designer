> Спека для быстрого контекста. Источник истины — CSS-файл и страница компонента. При изменении компонента обновляй эту спеку и блок в specs/_cheatsheet.md.

## Назначение
Иллюстрация + заголовок + опциональный текст + опциональные действия — для пустого списка/таблицы, отсутствия результатов поиска, первого входа без данных и полноэкранных ошибок (404/500/недоступность).

## Инварианты
- Рендерится только после завершения запроса — не как промежуточное состояние загрузки (это роль Spinner/Skeleton).
- Заголовок (`.es__title`) — всегда однострочный эллипсис; текст (`.es__text`) переносится свободно (`overflow-wrap`).
- Размеры M/L задают фиксированные паддинги и размер иллюстрации — компонент не масштабируется автоматически под контейнер.
- `.es--card` (своя рамка/фон/радиус) — только когда компонент стоит отдельно, не встроен в уже оформленный контейнер (Table/Tile/страница).

## Диагностика
- «Заголовок обрезается неожиданно» → по спеке он всегда однострочный эллипсис — сократить текст, не менять CSS
- «Компонент показан во время загрузки» → заменить на Spinner/Skeleton, EmptyState — только финальное состояние

## Ключевые правила (из разделов страницы)
- **Использование** — пустой список/таблица (фильтр, поиск, нет данных), ошибка запроса на весь экран/раздел. Не для паузы загрузки (там Spinner/Skeleton), не для одного пустого поля (там тире «—» в Entity/ReadOnlyField), не для системной строки внутри дропдауна (там компактный `.ddl__state--empty` в DropdownList).
- **Анатомия** — Иллюстрация (`.illu`, декоративна) → Заголовок (обязателен) → Текст (опционален) → Действия (опциональны, до 2 кнопок).
- **Варианты** — Размер: M (по умолчанию, встроен в контейнер) / L (полноэкранный). Поверхность: обычная (наследует контейнер) / `.es--card` (своя рамка и фон, для отдельно стоящего состояния). Действия: 0/1/2 кнопки.
- **Размеры** — M: иллюстрация 96×96, заголовок 18/24 Text Strong, текст 16/20 Text, макс. ширина текста 360px, паддинг 48/24. L: иллюстрация 160×160, заголовок 22/24 Display Strong, текст 18/24 Text, макс. ширина 420px, паддинг 80/24.
- **Размеры · Радиус скругления** — Радиус есть только у карточного варианта. Card — 16px (--radius-card) · Inline — 0.
- **Контент** — заголовок — одна строка, называет ситуацию, без извинений; текст — 1–2 предложения, не повторяет заголовок; основное действие — глагол-выход из ситуации; не больше двух кнопок; иллюстрация по смыслу должна соответствовать ситуации (не путать «всё выполнено» с ошибкой сервера).
- **Поведение** — статичен; рендерится только после завершения запроса (нет строк/ошибка) — не как промежуточное состояние; при появлении в ответ на действие пользователя (фильтр/поиск) — `role="status" aria-live="polite"` на контейнере-родителе на момент подстановки; действие обязано вести к разблокировке, не быть no-op.
- **Состояния** — одно статическое; соседние состояния места принадлежат другим компонентам (Spinner/Skeleton — загрузка; реальный контент — есть данные).
- **Доступность** — `.es__illu` — `aria-hidden="true"`; заголовок/текст — обычные `<p>`, не `<hN>`; `role="status" aria-live="polite"` — на родителе, не на `.es`, при асинхронной подстановке.
- **Типографика** — см. «Размеры».
- **Цвета** — заголовок `--text-primary`, текст `--text-secondary`; `.es--card` — фон `--bg-tile`, рамка `--border-light`; иллюстрация не тонируется (собственная палитра библиотеки).
- **Бэклог (Предложение, не реализовано)** — компактный вариант без иллюстрации для узких контейнеров (нужен реальный кейс); консолидация системных «нет результатов» DropdownList/InputAutocomplete/TableFilter поверх этого компонента — при экстракции их рантайма (Фаза 3).

## Для разработчиков (выжимка)

### Точные размеры (redline)
Таблица рендерится на странице через `getComputedStyle`. Точные значения — в `styles/empty-state.css`.

### Разметка · HTML (эталонная реализация ДС)

```html
<div class="es es--m">
  <span class="illu es__illu" data-illu="empty-folder" aria-hidden="true"></span>
  <div class="es__body">
    <p class="es__title">Нет сделок</p>
    <p class="es__text">По заданным фильтрам сделки не найдены. Попробуйте изменить условия поиска.</p>
  </div>
  <div class="es__actions">
    <button class="btn btn--accent btn--m"><span class="btn__label">Сбросить фильтры</span></button>
    <button class="btn btn--transparent btn--m"><span class="btn__label">Завести сделку</span></button>
  </div>
</div>
```

### Поведение · псевдокод (framework-agnostic)
1. Рендерить только после завершения запроса (нет строк или ошибка) — не как промежуточное состояние; во время самого запроса — Spinner/Skeleton.
2. Иллюстрация — декоративный слот `.illu`, `aria-hidden="true"`; имя — `data-illu`, SVG подставляет `ds-illustrations.js`.
3. Появление в ответ на действие пользователя (фильтр/поиск) → `role="status" aria-live="polite"` на контейнере-родителе (не на `.es`) на момент подстановки — озвучить переход один раз.
4. Не более двух действий, порядок — основное слева; обработчик основного действия обязан вести к разблокировке (сброс фильтра/повтор запроса/переход к созданию), не быть декоративным.
5. `.es--card` — только когда компонент не встроен в уже оформленный контейнер (Table/Tile/страница); иначе — рамка в рамке.

### Справочник классов и атрибутов

| Класс/атрибут | Назначение |
|---|---|
| `.es` | корень — требует размерный класс `--m`/`--l` |
| `.es--m` / `.es--l` | размер: встроенный (96px илл.) / полноэкранный (160px илл.) |
| `.es--card` | поверхность-карточка: фон `--bg-tile`, рамка `--border-light` |
| `.es__illu` | слот иллюстрации (`.illu` + `data-illu`) |
| `.es__body` | обёртка заголовка и текста, задаёт макс. ширину |
| `.es__title` / `.es__text` | заголовок (обязателен) / текст (опционален) |
| `.es__actions` | ряд действий, до 2 кнопок `.btn` |
