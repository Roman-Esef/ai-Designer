> Спека для быстрого контекста. Источник истины — CSS-файл и страница компонента. При изменении компонента обновляй эту спеку и блок в specs/_cheatsheet.md.

## Назначение
Переиспользуемый плейсхолдер загрузки, повторяющий геометрию будущего контента: строка текста (Line) и форма (Block), с общим шиммером. Показывает структуру раньше данных, чтобы макет не сдвигался, когда контент приходит.

## Инварианты
- Повторяет геометрию будущего контента (ширина/высота/радиус совпадают с реальным элементом) — не абстрактная плашка.
- `.sk-surface` сохраняет размер и радиус элемента, на котором стоит — шиммер поверх, не замена размеров.
- Не для короткой мгновенной паузы — там Spinner; Skeleton для заранее известной структуры (карточка, строка, тайл).

## Диагностика
- «Скелетон другого размера, чем реальный контент» → задать `--sk-h`/`--sk-w` под фактическую геометрию, не оставлять дефолт

## Ключевые правила (из разделов страницы)
- **Использование** — известная заранее структура контента (карточка, строка таблицы, тайл). Не для одной мелкой детали (там Spinner/`.btn--loading`), не когда структура непредсказуема, не как блокирующий оверлей произвольной области (там оверлей Spinner).
- **Анатомия** — Block (ведущая форма) + Line (строка текста) + Surface (шиммер прямо на существующем элементе, `.sk-surface`) + общий шиммер (движущийся блик поверх сплошной заливки).
- **Варианты** — Высота строки: Title 20px / Body 16px (по умолчанию) / Caption 12px. Форма блока: Rect (по умолчанию) / Rounded / Circle. Состав: одна строка / `.sk-group` (стопка строк) / `.sk-row` (блок + группа строк) / `.sk-surface` (на реальном элементе, без замены разметки — сохраняет его размер и радиус).
- **Размеры** — Line: фиксированная шкала высот (12/16/20), ширина всегда снаружи (`--sk-w`). Block: без собственного размера — всегда равен размеру заменяемого элемента (`--sk-w`/`--sk-h`).
- **Размеры · Радиус скругления** — Радиус задан типом плейсхолдера, не высотой. Line — 4px (--radius-xs) · Block — 6px (--radius-s) · Block Rounded — 12px (--radius-xl) · Block Circle — 50%.
- **Контент** — без текста; ширины строк — с разбросом (60–100%), последняя строка абзаца короче (60–75%).
- **Поведение** — шиммер `background-position` `1.6s ease infinite`, без синхронизации вручную (общий таймер при одновременном монтировании); `prefers-reduced-motion` → `3.2s`; реальный контент заменяет плейсхолдер в том же месте DOM.
- **Состояния** — одно состояние (показан, пока не заменён реальным контентом).
- **Доступность** — `.sk-line`/`.sk-block` — `aria-hidden="true"`; контейнер — `aria-busy="true"`, для длинных списков — `role="status" aria-live="polite"`.
- **Типографика** — не применимо (нет текста); высоты строк ориентируются на типографическую шкалу.
- **Цвета** — один нейтральный дуэт токенов: `--st-disabled-light` (база) / `--st-disabled-midlight` (пик волны), не тонируется.
- **Бэклог (Предложение, не реализовано)** — EmptyState (соседняя задача бэклога ДС: что показать, когда данные пришли, но их нет). Консолидация локальных реализаций (Modal, Popover, ReadOnlyField, Entity, TableCell/Table) на этот общий компонент выполнена — все они теперь используют `.sk-line`/`.sk-group`/`.sk-row`/`.sk-surface`.

## Для разработчиков (выжимка)

### Точные размеры (redline)
Таблица рендерится на странице через `getComputedStyle`. Точные значения — в `styles/skeleton.css`.

### Разметка · HTML (эталонная реализация ДС)

```html
<!-- строка -->
<span class="sk-line sk-line--title" style="--sk-w:60%" aria-hidden="true"></span>

<!-- группа строк (абзац) -->
<div class="sk-group">
  <span class="sk-line sk-line--title" style="--sk-w:45%"></span>
  <span class="sk-line" style="--sk-w:100%"></span>
  <span class="sk-line" style="--sk-w:65%"></span>
</div>

<!-- строка с ведущим блоком (аватар + строки) -->
<div class="sk-row" aria-busy="true">
  <span class="sk-block sk-block--circle" style="--sk-w:40px;--sk-h:40px"></span>
  <div class="sk-group">
    <span class="sk-line sk-line--title" style="--sk-w:48%"></span>
    <span class="sk-line" style="--sk-w:72%"></span>
  </div>
</div>
```

### Поведение · псевдокод (framework-agnostic)
1. Ширины строк — не константа: подмешивать случайный разброс (60–100%); последняя строка абзаца короче (60–75%).
2. Skeleton заменяется целиком, одним снимком — не подменять отдельные строки по мере прихода полей одного объекта.
3. Анимируется только `background-position`, не `opacity`/`transform` — дешевле при большом числе одновременных плейсхолдеров.
4. `prefers-reduced-motion` → `animation-duration` ×2, не отключение.
5. Контейнер во время загрузки — `aria-busy="true"`; длинный список/таблица — дополнительно `role="status" aria-live="polite"`.

### Справочник классов и атрибутов

| Класс/атрибут | Назначение |
|---|---|
| `.sk-line` | строка текста; высота по умолчанию 16px (Body) |
| `.sk-line--title` / `--caption` | 20px / 12px |
| `.sk-block` | форма (по умолчанию прямоугольник); размер — `--sk-w`/`--sk-h` |
| `.sk-block--rounded` / `--circle` | скруглённый / круглый |
| `.sk-group` | стопка строк с зазором 8px |
| `.sk-row` | ведущий блок + `.sk-group` в строку, зазор 12px |
| `.sk-surface` | шиммер прямо на существующем элементе — не меняет его размер/радиус/дочерние элементы скрывает через `visibility:hidden` |
| `aria-hidden="true"` | на каждом `.sk-line`/`.sk-block` — декоративны |
| `aria-busy="true"` | на контейнере, пока идёт загрузка |
