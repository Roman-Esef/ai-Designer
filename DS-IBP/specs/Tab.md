> Автоспека для быстрого контекста. Источник истины — CSS-файл и страница компонента. При изменении компонента обновляй эту спеку.

## Назначение
Таб — инструмент переключения между разными вьюхами одного экрана. По умолчанию горизонтальный таб подстраивается под размер контента, вертикальный — под размер контейнера. Размеры M и S, опциональные иконка и бейдж-счётчик.

## Инварианты
- Hover=focus — единая заливка, которая держится после клика, пока курсор не покинет таб (нативный `:hover`), без отдельного pressed.
- Индикатор выбора — CSS `::after`, привязан к общему рейлу контейнера (снизу у horizontal, слева у vertical), не к табу отдельно.
- Роль — переключение вьюх страницы (`role=tab`), в отличие от SegmentControl (переключение значения параметра) — компоненты не взаимозаменяемы.
- Disabled-таб остаётся в roving tabindex (`aria-disabled`, не нативный `disabled`).

## Диагностика
- «После клика подсветка не гаснет при уходе курсора» → ожидаемо: hover держится до `mouseleave`, не сбрасывается кликом
- «Disabled-таб выпадает из клавиатурной навигации» → должен быть `aria-disabled`, не атрибут `disabled`

## Ключевые правила (из разделов страницы)
- **Использование** — Табы переключают вьюхи в пределах одной страницы или модалки, не меняя контекст целиком. Горизонтальные — для разделов страницы и табов в шапке таблицы; вертикальные — для длинных списков разделов в модалках (фильтры, формы).
- **Анатомия** — Таб — это интерактивная зона с текстом и опциональными слотами, плюс индикатор выбора. Группа табов разделяет общий рейл: снизу — у горизонтальных, слева — у вертикальных.
- **Варианты · Ориентация** — Horizontal — табы в ряд с общим нижним рейлом; ширина каждого таба тянется по контенту. Vertical — табы в столбец с общим левым рейлом; ширина таба равна ширине контейнера, бейдж прижат к правому краю. Попробуйте переключить — табы рабочие, можно ходить стрелками с клавиатуры.
- **Размеры** — Горизонтальные паддинги зависят от ориентации, не от размера: горизонтальный таб (M и S) — 8px слева и справа; вертикальный (M и S) — 16px слева и 8px справа. Два размера. M — базовый для страниц и модалок. S — для плотных мест и узких модалок. Высота таба и кегль текста зависят от размера.
- **Размеры · Радиус скругления** — Сам таб не скруглён — форму задаёт маркер; от размера радиусы не зависят. таб — 0 · маркер и бейдж — 999px (--radius-pill) · стрелка прокрутки — 50% · меню «Ещё» — 12px (--radius-popup) · пункт меню — 8px (--radius-control).
- **Состояния** — Невыбранные и выбранные табы проходят через Default и Hover = Focus, плюс Disabled — отдельного состояния нажатия (Active) нет. Hover и Focus визуально совпадают — единая заливка --primary-bg (Active · PrimaryBG), одинаковая для выбранного и невыбранного таба. Клик переводит таб в Selected, а заливка остаётся как при наведении, пока курсор не покинет таб — отдельного pressed-стейта не требуется. Бейдж при этом цвет не меняет: он одинаковый у выбранного и невыбранного таба во всех состояниях.
- **Варианты · Бейдж** — Бейдж отображается опционально. В нём может быть только целое число, и оно показывается с разбиением на разряды (1 234). Минимальная ширина бейджа — 20 / 16px для размеров M / S. На горизонтальных табах бейдж прижат к тексту, на вертикальных — к правому краю таба.
- **ИконкаНовое** — Слева к тексту можно добавить ведущую иконку — для табов-разделов с понятной семантикой. Отдельный кейс — таб только с иконкой (переключатель вида списка / сетки); такому табу обязателен aria-label.
- **Переполнение** — Два паттерна для горизонтальных табов, когда их больше, чем помещается по ширине контейнера. Скролл (по умолчанию) — ряд прокручивается по горизонтали, скроллбар скрыт; по краям появляются стрелки, когда в эту сторону ещё есть куда скроллить, а выбранный таб подскролливается в зону видимости. Fit + меню «Ещё» — показываются только табы, помещающиеся целиком, остальные уходят в выпадающий список за иконкой из трёх точек; включается атрибутом `data-tabs-overflow="menu"` на `.tabs`. Оба паттерна активируются сами по факту переполнения — рантайм `ds-tabs.js` оборачивает разметку, экрану ничего писать не нужно (RulesAudit W2, 12.08.2026). У вертикального таба слишком длинный текст обрезается многоточием с тултипом.
- **Равная ширина (Fitted)Предложение** — Режим, в котором табы делят ширину контейнера поровну — для сегмент-переключателей с коротким набором опций (период, режим отображения). Это альтернатива контентной ширине горизонтальных табов.
- **Типографика** — Текст таба набирается гарнитурой SB Sans Text, начертание Regular во всех состояниях, включая выбранный. Кегль зависит от размера; letter-spacing 0.
- **Контент** — Текстовое содержимое таба — короткая метка и опциональный числовой бейдж-счётчик.
- **Использование · Правила** — Таб переключает вьюхи в пределах одного экрана. Каждая пара «так / не так» ниже раскрывает одну конкретную ситуацию — не смешивайте разные правила в одном сравнении.
- **Доступность** — Группа табов — role="tablist", каждый таб — role="tab" с aria-selected. В таб-порядке участвует только выбранный таб (roving tabindex) — у остальных tabindex="-1", они достижимы стрелками. CSS красит выбранный/отключённый таб напрямую по `[aria-selected="true"]`/`[aria-disabled="true"]` — классы `.tab--selected`/`--disabled` нужны только для форс-состояний витрины (RulesAudit W1, 12.08.2026). `[aria-current="true"]` даёт тот же вид — для scroll-spy якорной навигации (TableFilter), где активный пункт не `role="tab"`.
- **Цвета** — Невыбранный таб по умолчанию окрашен в Text_Secondary (текст и иконка), при наведении переходит на Text_Primary; бейдж — на StSystem_MidLight. Выбранный таб — текст на Text_Primary, индикатор и иконка на Primary (Emerald). Disabled — на рампе StDisabled.

### Разметка · HTML (эталонная реализация ДС)

```
<!-- группа: горизонтальные табы, второй выбран -->
<div class="tabs tabs--horiz" role="tablist">
  <button type="button" class="tab tab--m" role="tab" aria-selected="false" tabindex="-1">
    <span class="tab__label">Обзор</span>
  </button>

  <button type="button" class="tab tab--m tab--selected" role="tab" aria-selected="true" tabindex="0">
    <span class="tab__icon"><i data-icon="layout-grid-01"></i></span>
    <span class="tab__label">Сделки</span>
    <span class="tab__badge">12</span>
  </button>
</div>
```

### Рантайм ДС — `scripts/ds-tabs.js`

Общий рантайм Tab и SegmentControl: roving tabindex, навигация стрелками
(← → и ↑ ↓), Home / End, активация выбора на месте, пропуск отключённых
элементов. У сегмент-контрола он же измеряет и двигает индикатор, у табов —
подскролливает выбранный таб в зону видимости внутри ленты.

Подключение — opt-in атрибутом на контейнере (чтобы рантайм не «оживлял»
статичные примеры состояний в витрине):

```
<div class="tabs tabs--horiz" role="tablist" data-tabs>…</div>
<div class="segctrl" role="radiogroup" aria-label="Период" data-segctrl>…</div>
```

API: `DSTabs.tabs(el, opts)`, `DSTabs.segment(el, opts)`,
`DSTabs.positionThumb(el)`, `DSTabs.wireAll(root)`.
Возвращает `{ el, items(), select(elОrIndex), value(), refresh() }`;
`opts.onChange(index, el)` — коллбэк смены выбора,
`opts.scrollIntoView: false` — отключить подскролл выбранного таба.

Переполнение горизонтального ряда (`.tabs--horiz`) рантайм активирует сам —
ряд шире контейнера сам получает обёртку со скроллом и стрелками (default),
или fit + меню «Ещё» через атрибут `data-tabs-overflow="menu"` на `.tabs`
(`"none"` — отключить, граница остаётся на вызывающей стороне). Оба паттерна
живут в `ds-tabs.js`, страница ничего не пишет вручную (RulesAudit W2, 12.08.2026).

Индикатор сегмент-контрола пересчитывается на resize, load, `document.fonts.ready`
и через ResizeObserver: метрики шрифта меняют ширину сегмента уже после первого
рендера, поэтому позицию нужно измерять, а не считать по индексу.

### Поведение · псевдокод (framework-agnostic)

```
// 1. Клик/Enter/Space по табу → снять tab--selected/aria-selected со всех, поставить на текущий,
//    tabIndex текущего = 0, у остальных = -1 (roving tabindex)

// 2. Клавиатура на [role="tablist"]:
//    ArrowRight/ArrowDown (horiz/vert) → следующий таб (зациклено), сразу активировать
//    ArrowLeft/ArrowUp     → предыдущий таб (зациклено), сразу активировать
//    Home / End            → первый / последний доступный (non-disabled) таб

// 3. Hover = Focus — единый визуальный стейт-слой (см. «Состояния»); клик не добавляет
//    отдельного pressed-состояния — заливка держится как hover, пока курсор не покинет таб

// 4. Overflow: измерить ширину контейнера и суммарную ширину табов —
//    лишние уходят в «⋯»-меню, либо контейнер скроллится с появляющимися стрелками
//    (рабочая реализация — DSTabs.tabs() в ds-tabs.js, активируется сама по факту переполнения)

// 5. Disabled: pointer-events: none, tabIndex = -1, aria-disabled = true
```

### Tab.types.ts

```
type TabOrientation = 'horizontal' | 'vertical';
type TabSize = 'm' | 's';

interface TabItem {
  value: string;
  label?: React.ReactNode;        // опустить для icon-only — тогда обязателен ariaLabel
  icon?: React.ReactNode;
  badge?: number;                 // целое число, рендерится с разбиением на разряды
  disabled?: boolean;
  ariaLabel?: string;
}

interface TabsProps {
  items: TabItem[];
  value: string;                                // controlled-компонент
  onChange: (value: string) => void;
  orientation?: TabOrientation;                  // по умолчанию 'horizontal'
  size?: TabSize;                                // по умолчанию 'm'
  fitted?: boolean;                            // равная ширина сегментов (Предложение)
  overflow?: 'scroll' | 'menu';              // паттерн переполнения, по умолчанию 'scroll' (data-tabs-overflow)
  'aria-label': string;                       // обязателен на tablist
}
```
