> Спека для быстрого контекста. Источник истины — CSS-файл и страница. При изменении обновляй эту спеку и блок в specs/_cheatsheet.md.

## Назначение
Правила построения любого экрана продукта: из каких зон складывается страница, какие у зон размеры и поля, что скроллится, а что залипает. Все экраны — стартовая с навигационными тайлами, реестр с таблицей, карточка сущности — строятся по одному каркасу: панель навигации слева, рабочая область справа, внутри рабочей области зона крошек над контентной областью.

## Инварианты
- Между панелью навигации и рабочей областью отступа нет — шов вплотную; отступ слева резервирует сам `.nav-layout` (56px в rail/drawer, 272px в fixed).
- Между зоной крошек и контентной областью отступа нет — контент начинается сразу под крошками (у контентной области `padding-top: 0`).
- Поля контентной области — 24px слева и справа, 24px снизу; сверху 0. Другого значения полей у экрана нет: полноэкранных режимов, снимающих боковые поля, в продукте нет.
- Зона крошек — 44px и поля 24px по бокам — принадлежит компоненту Breadcrumbs, экран их не задаёт и не переопределяет.
- Крошки и контент выровнены по одной вертикали: поля зоны крошек совпадают с полями контентной области.
- Контентная область резиновая; на узком окне раскладка перестраивается по брейкпоинтам (блоки меняют число колонок и переходят один под другой), горизонтального скролла нет. **У экрана горизонтального скролла не бывает никогда** — адаптивная вёрстка закладывается при проектировании, а не постфактум; объект, выходящий за границу экрана, — баг. Исключение — контейнер, у которого скролл заложен в собственной раскладке: тело таблицы или отдельный тайл (не сама рабочая область). Шаги считаются от ширины рабочей области, а не окна: `.screen` объявлен размерным контейнером (`container-type: inline-size; container-name: screen`), экран пишет `@container screen (max-width: …)`. Причина — закрепление панели сужает контент на 216px без изменения вьюпорта: это общее для всех страниц, панель можно закрепить на любом экране. Общих для ДС значений пока нет, шаги задаёт экран (карточка сделки: 1560 / 1240 / 900px). Порог базово задаётся на уровне экрана; для экранов, где ширина контентной области меняется отдельно (растягиваемая правая панель), может понадобиться свой порог от ширины именно контентной области — точная формулировка правила не зафиксирована, см. бэклог страницы.
- Крошки залипают у верхней кромки (`position: sticky`), скроллится только контент.
- Панель навигации со страницей не скроллится: `position: fixed; height: 100vh`; внутри у списка пунктов (`.nav__list`) собственный скролл, верхний блок и подвал панели неподвижны.
- Колоночная сетка не дублируется в layout.css — это `.grid12` + `.col-N` из Spacing (12 колонок, зазор 16px).

## Диагностика
- «Крошки и заголовок страницы стоят на разных вертикалях» → у зоны крошек или контентной области переопределены поля; должно быть 24px и там, и там
- «Между крошками и контентом появился зазор» → у `.screen__content` задан `padding-top` или у `.crumbs` `margin-bottom`; оба должны быть 0
- «При скролле крошки уезжают вверх» → `.crumbs` не прямой ребёнок `.screen` (правило sticky навешено на `.screen > .crumbs`)
- «Контент прижат к панели навигации» → потерян `.nav-layout` вокруг панели и рабочей области

## Ключевые правила (из разделов страницы)
- **Использование** — Каркас обязателен для любого экрана продукта. Экран решает состав контента, каркас — зоны и поля. Единственное исключение — страницы вне приложения (логин, ошибка), где панели навигации и крошек нет.
- **Анатомия** — Три зоны: NavPanel (`.nav`, слева, фиксирована) · зона крошек (`.crumbs`, 44px, залипает) · контентная область (`.screen__content`, поля 24px). Обёртки: `.nav-layout` (панель + рабочая область), `.screen` (рабочая область).
- **Варианты** — По режиму навигации: rail (56px), drawer (оверлей поверх rail-отступа), fixed (272px, контент ужимается). По контенту: тайлы (`.grid12`), таблица во всю ширину контентной области, карточка сущности. Крошки есть всегда, кроме Дашборда.
- **Размеры** — Отступ панели: 56px / 272px (fixed). Зона крошек: высота 44px, padding 16/24/12. Контентная область: padding 0 24px 24px. Вертикальный ритм блоков контента: 24px.
- **Контент** — Заголовок страницы — PageHeader, первый блок контентной области. Далее блоки в один поток с зазором 24px; последний заканчивается полем 24px — закреплённого снизу подвала действий в продукте нет. Горизонтальная структура — сетка `.grid12`, вертикальная — шкала Spacing.
- **Поведение** — Скроллится только контент; крошки залипают; панель фиксирована на высоту вьюпорта, её список прокручивается сам. Переключение режима панели меняет отступ слева чистым CSS (`:has()`), контент ужимается. На узком окне раскладка перестраивается по брейкпоинтам, горизонтального скролла нет.
- **Состояния** — Собственных нет: каркас статичен, состояния принадлежат вложенным компонентам.
- **Доступность** — Ориентиры: `<nav aria-label="Главное меню">`, `<nav aria-label="Хлебные крошки">`, `<main>` для контентной области. Порядок в DOM = порядок чтения: панель → крошки → контент.
- **Типографика** — Не применимо: каркас текста не содержит.
- **Цвета** — Фон рабочей области и зоны крошек — `--bg-page`; фон панели — `--bg-mainmenu`; поверхности контента (тайлы, таблицы) — `--bg-tile`.

## Для разработчиков (выжимка)

### Точные размеры (redline)
Таблица рендерится на странице через getComputedStyle на живом каркасе. Значения — токены в `styles/layout.css` (`--layout-*`), `styles/nav-panel.css`, `styles/breadcrumbs.css`.

### Разметка · HTML (эталонная реализация ДС)

```
<div class="nav-layout">
  <nav class="nav nav--rail" aria-label="Главное меню">…</nav>
  <div class="screen">
    <nav class="crumbs" aria-label="Хлебные крошки" data-breadcrumbs>
      <li class="crumbs__item"><a class="link link--muted" href="/">Главная</a></li>
      <li class="crumbs__item crumbs__item--current"><span class="crumbs__current" aria-current="page">Коды RWA</span></li>
    </nav>
    <main class="screen__content">
      <header class="phead">…PageHeader…</header>
      <div class="grid12"><section class="col-3">…</section></div>
    </main>
  </div>
</div>
```

### Справочник классов и атрибутов

| Класс/атрибут | Назначение |
|---|---|
| `.nav-layout` | Обёртка панели и рабочей области; резервирует отступ слева по режиму панели (NavPanel) |
| `.screen` | Рабочая область: колонка, `min-height:100vh`,, фон `--bg-page` |
| `.screen > .crumbs` | Зона крошек: sticky у верхней кромки, `z-index:3`, фон `--bg-page` |
| `.screen__content` | Контентная область: `padding: 0 24px 24px`, колонка с зазором 24px |
| `.grid12` / `.col-N` | Колоночная сетка (Spacing): 12 колонок, зазор 16px |
| `--layout-pad-x` / `--layout-pad-bottom` / `--layout-crumbs-h` / `--layout-block-gap` | Токены каркаса: 24px / 24px / 44px / 24px |
