> Спека для быстрого контекста. Источник истины — CSS-файл и страница компонента. При изменении компонента обновляй эту спеку и блок в specs/_cheatsheet.md.

## Назначение
Круговой индикатор загрузки неопределённой длительности. Стоит там, где ProgressBar не подходит: инлайн рядом с текстом, самодостаточное кольцо без выделенной полосы в разметке, либо блокирующий оверлей поверх области, которая сейчас обновляется.

## Инварианты
- Для неизвестной длительности (секунды); известное значение — ProgressBar, не Spinner.
- `--current` наследует цвет текста хоста (currentColor); тоновый вариант (accent/success/…) — фиксированный трек+акцент — не смешивать в одном инстансе.
- `.spin-overlay` растягивается на родителя (`position:relative` у родителя обязателен) — локальный оверлей, не полноэкранный (в отличие от `--modal-scrim`).

## Диагностика
- «Оверлей спиннера растянулся на весь экран» → родитель должен быть `position:relative`, оверлей берёт `inset:0` именно от него
- «Спиннер внутри кнопки не того цвета» → использовать `.spin--current` (currentColor), не тоновый `.spin--accent` и т.п.

## Ключевые правила (из разделов страницы)
- **Использование** — неизвестная длительность, короткий процесс (секунды). Не для известного значения (см. ProgressBar), не для загрузки внутри кнопки (`.btn--loading` уже включает свой спиннер), не для сохранения структуры контента при загрузке (нужен Skeleton — в бэклоге ДС, не создан).
- **Анатомия** — один элемент, двухцветная обводка: Трек (`--border-light`, неподвижный) + Индикатор (сегмент, цвет = тон, вращается). Подпись — опциональный внешний слот.
- **Варианты** — Тон: accent/success/warning/error/info/system/inverse (7). Состав: голое кольцо / кольцо + подпись (в строку `.spin-group` / столбиком `.spin-group--stack`) / блокирующий оверлей `.spin-overlay`.
- **Размеры** — XS 16px / S 20px / M 24px (по умолчанию) / L 32px; толщина кольца 2px (XS/S) и 3px (M/L).
- **Размеры · Радиус скругления** — Круг во всех размерах. кольцо XL/L/M/S — 50% (--radius-circle).
- **Контент** — подпись в форме процесса («Сохранение…»), без процента/счётчика.
- **Поведение** — вращение на `transform: rotate()`, `.8s linear infinite`; `prefers-reduced-motion` → `1.6s` (не отключается). Оверлей — `position:absolute; inset:0` поверх позиционированного родителя, фон — вуаль на `--bg-page` (82%), НЕ модальный `--modal-scrim`; z-index локальный, не часть глобальной шкалы.
- **Состояния** — одно состояние (вращается/не смонтирован); нет Disabled/Hover.
- **Доступность** — `role="status"` (не `progressbar` — нет значения); без подписи обязателен `aria-label` на кольце; оверлей — `role="status"` + `aria-live="polite"`.
- **Типографика** — подпись `--type-body-s`; подпись оверлея `--type-body-s-strong`.
- **Цвета** — трек `--border-light` (Inverse: `--text-on-dark` 28%); индикатор — статусные токены (`--primary`, `--st-green/orange/red/lblue/system`, Inverse: `--text-on-dark`).
- **Бэклог (Предложение, не реализовано)** — Skeleton (переиспользуемый примитив с шиммером), составной upload-индикатор с отменой/повтором. Круговой ProgressBar со значением — отдельная задача в бэклоге ProgressBar, не здесь.

## Для разработчиков (выжимка)

### Точные размеры (redline)
Таблица рендерится на странице через `getComputedStyle`. Точные значения — в `styles/spinner.css`.

### Разметка · HTML (эталонная реализация ДС)

```html
<!-- голое кольцо -->
<span class="spin spin--m spin--accent" role="status" aria-label="Загрузка"></span>

<!-- с подписью -->
<div class="spin-group" role="status">
  <span class="spin spin--m spin--accent" aria-hidden="true"></span>
  <span class="spin-group__label">Сохранение…</span>
</div>

<!-- оверлей — родитель обязан быть position:relative -->
<div class="spin-overlay" role="status" aria-live="polite">
  <span class="spin spin--l spin--accent" aria-hidden="true"></span>
  <span class="spin-overlay__label">Обновление…</span>
</div>
```

### Поведение · псевдокод (framework-agnostic)
1. Никогда не рендерить `aria-valuenow`/процент — Spinner всегда неопределённый (иначе это ProgressBar).
2. Вращение только через CSS `transform: rotate()`, не покадровым изменением угла из JS.
3. Компонент монтируется на время процесса и размонтируется по завершении — нет состояния «остановлено».
4. Оверлей: убедиться, что ближайший позиционированный предок — сама блокируемая область; `aria-live="polite"` объявляет конец блокировки только при реальном удалении из DOM (не `visibility`/`opacity`).
5. `prefers-reduced-motion` → `animation-duration` ×2, не отключение.

### Справочник классов и атрибутов

| Класс/атрибут | Назначение |
|---|---|
| `.spin` | корень — кольцо (трек + вращающийся индикатор) |
| `.spin--xs/s/m/l` | размер |
| `.spin--accent/success/warning/error/info/system/inverse` | тон |
| `.spin-group` / `.spin-group--stack` | кольцо + подпись, в строку / столбиком |
| `.spin-group__label` | текст подписи |
| `.spin-overlay` / `.spin-overlay__label` | блокирующий оверлей области и его подпись |
