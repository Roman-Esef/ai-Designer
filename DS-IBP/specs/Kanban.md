## Назначение
Доска: горизонтальный трек колонок-этапов с карточками, которые переносятся между этапами перетаскиванием или с клавиатуры. Отвечает на вопрос «как распределена работа и что застряло», в отличие от Table, который отвечает «какие объекты есть и что в них». Колонка (`.kbcol`) — организм доски; карточка — вложенный компонент, собранный на **Card** (`.tile.tile--card` + раскладка `.kbcard`).

## Инварианты
- **Скроллпорт и ряд колонок — разные элементы, и свести их в один нельзя.** Оба скролла принадлежат `.kanban__viewport` (высота определённая, `flex: 1; min-height: 0`), ряд `.kanban__track` лежит внутри и имеет высоту `auto`. Только так `stretch` тянет колонки по самой длинной колонке, а не по видимой области. Своего скролла у колонок нет; шапки залипают (`position: sticky`). Третьего скролла быть не должно.
- **`align-items` у ряда не переопределять** и высоту ему не задавать. Колонка обязана быть высотой во весь ряд — иначе ломается сразу двумя способами: (1) карточки, не влезшие в коробку колонки, торчат за ней, и заливка hover вместе с целью дропа кончаются раньше карточек; (2) `position: sticky` держит шапку только внутри её колонки — коробка кончилась, шапка уехала. Оба режима отказа наблюдались: с `flex-start` отваливались короткие колонки, с `stretch` на скроллпорте — все.
- **Хост-контракт.** Доска обязана получить определённую высоту: быть flex-элементом (`flex: 1; min-height: 0`) в колоночном родителе с заданной высотой. Иначе вьюпорту нечего ограничивать — скролл уезжает на страницу, залипания шапок нет.
- Липкая шапка колонки обязана иметь **непрозрачную** заливку: под ней едут карточки. Тона состояний в ДС полупрозрачные (`--primary-bg` — color-mix с transparent, `--bgtable-row-hover` — альфа-тон), поэтому кладутся `background-image`-слоем поверх непрозрачной базы `--bg-page`, а не вместо неё.
- Колонки прижаты друг к другу (`gap: 0`). Расстояние 16px между карточками соседних колонок даёт паддинг самих колонок, 8+8. По вертикали карточки стоят плотнее — зазор 8. Своей заливки в покое у колонки нет — только под указателем и при перетаскивании, и тон у обоих состояний один (`--primary-bg`); цель дропа отличает кольцо `--primary`, а не заливка.
- Ширина колонки задаётся переменной `--kb-col-w`, свои классы ширины экран не заводит (то же правило, что у Tile).
- Геометрию, типографику и состояния карточки задаёт **Card**, а не доска: Default / Hover / Active / Move / Disabled живут в `styles/tile.css`. Доска добавляет только Ghost, Selected и Error.
- **Статусной модели внутри компонента нет и не будет.** Kanban общий: на нём живут сделки, задачи, заметки, заявки. Ограничения переходов — предметная логика решения; доска даёт для неё одну точку входа, отменяемое событие `kanban:beforemove`. Зашивать матрицу переходов в рантайм значит навязать её всем потребителям.
- Модификатор состояния должен перебивать `:hover`. `.kbcol:hover` — это (0,2,0), голый `.kbcol--drop` — (0,1,0); клон летит с `pointer-events: none`, поэтому колонка под курсором ВСЕГДА в hover, и серый тон затирает подсветку цели. Отсюда `.kbcol.kbcol--drop` ниже по файлу плюс гашение hover-тона на время жеста (`.kanban.is-dragging`).
- На время переноса выделение текста выключается на всём документе (`body.kb-dragging`), а не только на доске: указатель уходит за пределы трека, и браузер тянет выделение по странице.
- Порядок карточек в колонке значим — его задаёт пользователь. Автосортировки нет.

## Ключевые правила (из разделов страницы)
- **Использование** — брать, когда у объекта линейная модель из 3–7 этапов, важно распределение, объектов десятки и статус меняют вручную. Не брать для сравнения значений (это Table), при 7+ этапах и для массового ввода данных. Доска и реестр — две вьюхи одних данных, переключатель обязателен, фильтр переживает переключение.
- **Анатомия** — доска (тулбар + трек + заглушка «Добавить колонку»), колонка (липкая шапка с маркером, именем, счётчиком и тремя действиями + тело + линия вставки), карточка (Title Card, чипы под ним, действия, поля, метрики, подвал).
- **Варианты** — у доски: группировка, плотность, состав полей, число колонок. У колонки: тон маркера, свёрнутость, порядок (колонка переносится за шапку). У карточки: плотность и состав чипов. Модальных окон четыре, все — штатный Modal; панель деталей — штатный Drawer.
- **Размеры** — колонка 288 (с паддингом 8), карточка 272, свёрнутая колонка 48, зазор между карточками 8 по вертикали и 16 по горизонтали (паддинги соседних колонок), линия вставки 2px. Геометрия карточки — из Card: хэдер 16/16/8, контент 8/16/20.
- **Контент** — заголовок клэмпом 2 строки (1 в компактной) с тултипом при усечении; чипов не больше трёх, иконок у них нет кроме «Ключевой сделки»; полей не больше четырёх, значение в одну строку, пусто — прочерк; набор полей задаёт доска, а не карточка.
- **Поведение** — порог захвата 4px, pointer events, призрак на месте, индекс вставки по центрам, автоскролл по обеим осям, Esc возвращает карточку на исходное место. Колонка переносится за шапку: летит клон шапки, место показывает вертикальная линия, Esc возвращает колонку на исходный индекс. Ограничений переходов нет — их задаёт решение, слушая отменяемое `kanban:beforemove`. Клик по карточке мимо кнопок открывает Drawer (`data-kb-drawer`); жест, закончившийся переносом, панель не открывает. Перенос не подтверждается диалогом — снекбар с «Отменить»; удаление подтверждается alertdialog.
- **Состояния** — карточка: Default / Hover / Active / Move / Disabled (Card) + Ghost / Selected / Error (доска). Колонка: Default / цель дропа / дроп запрещён / свёрнута / пустая. Доска: загрузка / нет колонок / фильтр без результатов.
- **Доступность** — 2.1.1 закрыт клавиатурным переносом и карточки, и колонки (шапке колонки рантайм сам ставит `tabindex` и `aria-roledescription`), 2.5.7 — пунктом «Переместить в…» в кебабе, 4.1.2 и 4.1.3 — ролями и `aria-live`. Линия вставки на `--primary-dark` (5.24:1), а не `--primary` (2.91:1 — ниже нормы 1.4.11).
- **Типографика** — Title Card `--type-h6-strong`; имя колонки и значение поля `--type-body-s(-strong)`; подписи и метрики `--type-body-xs`. Три размера на карточке — предел.
- **Цвета** — фон доски `--bg-page`, карточка `--bg-tile`, тона колонки `--bgtable-row-hover` и `--primary-bg`, маркеры на рампах `--st-*`, линия вставки `--primary-dark`.

## Диагностика
- «Шапка колонки просвечивает, под ней видно карточки» → заливка состояния положена вместо непрозрачной базы, а не слоем поверх неё
- «Скроллится вся страница вместо доски» → трек не получил `min-height: 0` в flex-родителе
- «Между карточками соседних колонок 8px вместо 16» → у трека выставлен `gap`, а он должен быть 0: расстояние даёт паддинг колонок
- «Карточка прыгает под курсор в момент захвата» → не сохранено смещение точки нажатия относительно кромки карточки
- «Список схлопывается при перетаскивании» → нет призрака `.kbcard--ghost`, карточка убрана из потока
- «Esc снял захват, но карточка осталась в чужой колонке» → не сохранено исходное место (колонка + следующий сосед)
- «Заголовок карточки не даёт тултип при усечении» → `DSTooltip.truncated` меряет и `scrollHeight`; проверить, что клэмп реально режет, а не текст короткий
- «Кебаб карточки удаляет не ту карточку» → меню общее на доску, нужен запомненный триггер открытия
- «Меню на доске перестали открываться после перерисовки» → экран пересобрал разметку через `innerHTML` и не позвал `DSMenu.bindAll(scope)` заново; рантаймы ДС связывают узлы один раз, на `DOMContentLoaded`
- «Шапки колонок отлипают то в одной колонке, то в другой» → у трека переопределён `align-items: flex-start`, колонки разной высоты
- «Колонка не подсвечивается как цель дропа» → `.kbcol:hover` (0,2,0) перебивает `.kbcol--drop` (0,1,0)
- «При перетаскивании выделяется текст на соседних карточках» → на время жеста не выставлен `body.kb-dragging`
- «Клик по карточке открывает панель после перетаскивания» → жест не отличён от клика: `pointerup` гасит состояние раньше, чем браузер дошлёт `click`, нужен собственный флаг

### Рантайм ДС — `scripts/ds-kanban.js`
Подключается через `scripts/ds.js`, оживляет любую разметку с `data-kanban` сам. Из коробки: перетаскивание указателем (порог 4px, плавающий клон, призрак, линия вставки, автоскролл по обеим осям, отмена по Esc), клавиатурный эквивалент, запрет дропа по модели с причиной в подсказке, счётчики и `aria-label` колонок, пустые состояния, звезда, сворачивание колонки, добавление и удаление карточек и колонок. Меню, подтверждения, снекбар и «усечено → тултип» делегируются штатным `DSMenu` / `DSModal` / `DSSnack` / `DSTooltip` — своих реализаций рантайм не заводит.

API: `DSKanban.bind(board)` · `bindAll(root)` · `move(card, col, index)` · `sync(board)`.
События (всплывают с доски): `kanban:move {card, from, to, index}` · `kanban:add` · `kanban:remove` · `kanban:star` · `kanban:colremove`.

### Поведение · псевдокод (framework-agnostic)

```
# захват
onPointerDown: armed = {card, x, y}
onPointerMove: if |dx|+|dy| < 4: return          # иначе клик станет микропереносом
               beginDrag once; moveFly; autoScroll(track, e); placeGuide(colUnder(e), y)

# оформление жеста — общее для карточки и колонки
beginDrag: board += 'is-dragging'      # гасит hover-тон, иначе он затрёт подсветку цели
           body  += 'kb-dragging'      # выделение текста выключено на всём документе
           selection.removeAllRanges() # и уже начатое — тоже

# ограничений переходов у доски НЕТ: их задаёт решение
allow(board, {card, from, to, index}):
    ev = CustomEvent('kanban:beforemove', cancelable: true)
    board.dispatch(ev)
    -> not ev.defaultPrevented          # preventDefault() вернёт карточку на место

# сброс и отмена
onPointerUp: if colUnder and guide and allow(...):
                 move(card, col, indexOfGuide()); emit('kanban:move'); snack
             else: cancelDrag()
onKeyDown(Esc): restoreTo(from, savedNextSibling)   # возвращает, а не снимает захват

# перенос колонки — ручка это шапка, летит клон шапки
onPointerDown(.kbcol__head): colArmed = {col, x, y}
placeColGuide(x): индекс по центрам колонок; линия в координатах трека + его scrollLeft
onPointerUp: putColumn(col, colAt); emit('kanban:colmove')
onKeyDown(Esc): putColumn(col, home)                # исходный индекс, а не «отпустить»

# клавиатура: шаг по колонкам, промахнуться нельзя
карточка: Space -> взять/положить · Left/Right -> соседняя колонка ·
          Up/Down -> сдвиг внутри колонки · Esc -> отмена с возвратом
колонка:  Tab до .kbcol__head (tabindex ставит рантайм) · Space -> взять/положить ·
          Left/Right -> переставить · Esc -> вернуть на исходный индекс
каждый шаг -> announce() в aria-live

# клик по карточке ≠ конец жеста
afterGesture = true при beginDrag; первый следующий click гасится и сбрасывает флаг,
иначе панель деталей открывалась бы после каждого переноса
```
