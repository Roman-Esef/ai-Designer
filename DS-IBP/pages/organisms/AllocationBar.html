AllocationBar

Итоговое числовое значение и его разбивка по составляющим: заголовок с суммой, стек-бар распределения и список позиций с долями. Компонент не знает предметной области — «Кредит», «РЕПО» и «Комиссия» приходят снаружи как данные. Служебные состояния собраны из Alert, кнопка раскрытия — Button Transparent XS, цвета сегментов — только токены --chart-* из Colors.

Использование

AllocationBar отвечает на вопрос «из чего складывается это число». Ставится в Tile на карточке сделки, в тело Modal с финансовыми метриками, в сайдбар детализации. Компонент read-only: не сортирует, не фильтрует и не редактирует значения.

В плитке карточки сделки

В модальном окне финансовых метрик

  • Когда использовать. Есть одно итоговое число и 1–12 слагаемых, сумма которых имеет смысл: структура обеспечения, состав задолженности, распределение лимита.
  • Когда не использовать. Значения не складываются в осмысленный итог (тогда — Entity или список ReadOnlyField); нужен клик по позиции с переходом в детализацию (оборачивайте компонент, не меняйте его); показателей больше 12 — распределение перестаёт читаться в баре.
  • Против ProgressBar. ProgressBar показывает одну величину относительно максимума («85% готово»). AllocationBar показывает состав целого: сегменты не соревнуются, а делят 100%.
  • Против Tile. Tile — контейнер с шапкой и подложкой; AllocationBar собственного фона не имеет и живёт внутри плитки, модалки или ячейки.

Анатомия

Три обязательных блока по вертикали с зазором 8px: шапка, бар, список. Подвал появляется, только если сумма позиций расходится с итогом.

  • .albar-host — хост с container-type: inline-size. Без него контейнерные запросы не работают и компонент останется в базовой раскладке
  • .albar__head — заголовок (+ опц. подзаголовок и иконка предупреждения) слева, итог справа; выравнивание по базовой линии
  • .albar__total — итог, Body M Strong; единица измерения (.albar__unit) — Body XS, цвет --text-inactive
  • .albar__bar — стек-бар 8px, радиус pill, зазор сегментов 2px, трек --st-grey-light. role="img" + текстовая сводка в aria-label
  • .albar__row — строка позиции: маркер 8px · название · процент · значение. Числовые колонки выровнены по правому краю, tabular-nums
  • .albar__foot — подвал: Alert ДС при partial (warning) или overflow (error). В штатном случае отсутствует

Варианты

Две независимые оси конфигурации: плотность данных (что показываем в строке) и количество позиций.

Режимы отображения

Флаги showPercent и showProgressBar дают четыре комбинации. По умолчанию включены оба.

Рекомендуемый режим: и доля, и абсолютное значение.

Без процентов

Когда важны рубли, а не доли.

Без бара

Для плотных мест и печати.

Минимальный

Количество позиций

Компонент стабилен от 1 до 12 позиций. Свыше maxVisibleItems (по умолчанию 5) список сворачивается под кнопку «Показать ещё N» — внутреннего скролла у компонента нет: вложенный скролл ломает прокрутку страницы и прячет данные.

Переполнение текста

Длинный подзаголовок

Заголовок и подзаголовок — одна строка с усечением и тултипом по title. Перенос в две строки не используется: ломает вертикальный ритм.

Большое число — компактный формат

Свыше 999 999 999 переключайтесь на format: "compact", иначе итог вытеснит заголовок.

Смешанные длины названий

Колонка названий обрезается по доступной ширине и не растягивается под самое длинное значение; числовые колонки остаются на месте.

Иконографика

  • Маркер позиции — круг 8px в цвете сегмента, не иконка. Единственная графика внутри строки.
  • Иконка предупреждения в шапке (.albar__warn) — alert-triangle-filled 16px в тоне --warning, между заголовком и итогом; всегда с тултипом, объясняющим причину. Пример — «Просроченная задолженность на сумму 123 млн. RUB».
  • Иконки состояний приходят из Alert ДС и отдельно не настраиваются.

Поведение

Связь бара и списка

Наведение на сегмент подсвечивает свою строку и приглушает остальные до opacity .4 — и наоборот. Переход 150ms ease. Сегменты — decorative graphics, не интерактивные элементы: для клика оборачивайте их в <button> на уровне продукта.

Минимальная ширина сегмента

Сегмент тоньше 2px неразличим. ResizeObserver добивает каждый ненулевой сегмент до min-width: 2px, а остаток ширины перераспределяет пропорционально между остальными. Позиция со значением 0 сегмента не получает вовсе, но в списке остаётся.

Ограниченная высота контейнера

Приоритет при нехватке высоты: итог не обрезается никогда → бар исчезает вторым → строки исчезают первыми.

A — влезает не весь список

Список уходит под fade-градиент, под ним — ссылка «Ещё N позиций». Скрытые строки остаются доступны скринридеру (mask, не display:none).

B — только шапка и бар

Детализация скрыта; сводка по позициям доступна тултипом на баре.

C — только шапка

Ниже 48px компонент использовать нельзя.

Растяжение

По умолчанию max-width: 600px. В резиновой сетке включайте .albar--stretch: бар и шапка занимают всю ширину, а содержимое строк остаётся в окне 600px от левого края — иначе название и значение расходятся по краям и связь между ними теряется.

Динамическое изменение размера

  • Пересчёт сегментов — через ResizeObserver на корне компонента, не по resize окна.
  • Структурные изменения (скрытие колонки процентов, переход строки в два ряда) — мгновенно, без transition.
  • Размерные (прозрачность сегментов, hover-подсветка) — 150ms ease. При prefers-reduced-motion анимации и шиммер отключаются.
  • Пока контейнер скрыт (закрытый аккордеон, неактивный таб), ширина равна 0 — пересчёт произойдёт на первом ненулевом ресайзе после раскрытия.

Состояния

Пять взаимоисключающих значений status и три производных от данных признака: partial (сумма меньше итога), overflow (больше) и нулевая позиция.

Loaded

Loading — быстрый (< 3 сек)

Полный скелетон: итог, бар и три строки. Шиммер 1,4s linear.

Loading — долгий расчёт (≥ 3 сек)

Скелетон остаётся у итога и бара, вместо строк — плашка «Данные рассчитываются». Пользователь понимает, что ожидание ожидаемо.

Error

Alert Error с кнопкой «Повторить» (Button Outline XS в тоне алерта). Код ошибки и стек в интерфейс не выводим.

Empty

Итог — прочерк, вместо списка строка «Нет данных» цветом Inactive. Плашка не используется: отсутствие данных — не ошибка.

Partial — сумма меньше итога

Нераспределённый остаток виден в баре серым сегментом, в подвале — Alert Warning с точной долей.

Overflow — сумма больше итога

Бар нормализуется по сумме, подвал — Alert Error: это дефект данных, а не оформления.

Позиция со значением 0

Строка отображается, сегмента в баре нет. Если все значения нулевые — компонент уходит в Empty.

Предупреждение в шапке

Признак поверх любого состояния: данные корректны, но требуют внимания.

Скринридер и цвет

  • бар — role="img" с aria-label, перечисляющим все позиции и доли;
  • доля никогда не кодируется только цветом — рядом с маркером всегда название и число;
  • строки под fade-градиентом скрыты маской, а не display: none, и остаются в дереве доступности;
  • Alert подвала наследует role="alert" / aria-live от тона (error и warning — assertive);
  • усечённые заголовок и название позиции дублируются в title;
  • кнопка «Показать ещё» — минимум 44×44px по тач-таргету в любом контейнере.

Поведение · псевдокод (framework-agnostic)

Поведение · псевдокод (framework-agnostic) 
// 1. Ветвление по состоянию — до любых расчётов.
//    Ветки взаимоисключающие, не оверлеи поверх loaded.
if status == 'loading'                      -> скелетон (fast) | скелетон + плашка расчёта (slow)
if status == 'error'                        -> шапка без итога + Alert error + «Повторить»
if status == 'empty' or items пуст
   or все items[].value == 0                -> шапка, итог = '—', строка «Нет данных»
else                                        -> обычный рендер

// 2. Нормализация позиций и назначение цвета.
for i, it in items:
  it.percent = it.percent ?? (total > 0 ? it.value / total * 100 : 0)
  it.color   = it.color   ?? PALETTE[i]        // 12 токенов --chart-*, без цикла
sum = Σ it.percent
partial  = sum < 99.5      // подвал Alert warning + серый сегмент остатка
overflow = sum > 100.5     // подвал Alert error, бар нормализуется по sum

// 3. Минимальная ширина сегмента (после каждого ресайза, через ResizeObserver
//    на корне; дебаунс кадром requestAnimationFrame).
w = ширина бара; MIN = 2px
для сегментов, чья доля * w < MIN:  flexBasis = MIN; flexGrow = 0
остальным: flexGrow = (доля / доля_остальных) * (w − MIN * количество_добитых)

// 4. Двунаправленная подсветка.
onEnter(node):  root.dataset.hover = node.id            // CSS гасит всё до .4
                строка и сегмент с этим id -> .is-active // возвращает 1
onLeave():      удалить root.dataset.hover

// 5. Сворачивание списка.
collapsed = items.length > maxVisibleItems (5) and not expanded
в баре отрисованы ВСЕ сегменты, в списке — первые maxVisibleItems
клик по «Показать ещё N» -> expanded = true (обратно в этом сеансе не сворачивается)

Рабочий референс на vanilla JS — window.AllocationBar.make(cfg) в scripts/allocation-bar.page.js. Форматтеры fmtNumber / fmtPercent / fmtCompact экспортируются оттуда же.

Бэклог

Кейсы, которых недостаёт документации, — на существующих токенах и компонентах.

  • Позиция «Прочее» — готовая свёртка 13-й и далее позиций в одну виртуальную с тултипом-расшифровкой. Сейчас это правило описано, но лежит на стороне продукта.
  • Сравнение с предыдущим периодом — дельта рядом с итогом (+234 567,89), как в блоке «Переоценка по PE» в продукте.
  • Кликабельные позиции — опциональный drill-down: строка как <button> с состояниями hover/focus, без изменения read-only-дефолта.

Конструктор

Соберите разбивку: количество позиций, ширина контейнера, состояние и соотношение суммы позиций с итогом. Ширина контейнера — главный параметр: от неё зависит вся раскладка. Демо обновляется наверху, панель настроек — две колонки.

Код компонента

Эталонная разметка и исходники AllocationBar: HTML — из спеки, CSS — styles/allocation-bar.css (полностью), JS — публичное API window.AllocationBar. Полный исходник JS живёт в scripts/allocation-bar.page.js.
