TableFilter

TableFilter — панель фильтра над таблицей. Кнопка «Фильтр» (Button Outline S) открывает модалку с параметрами фильтрации; применённый фильтр возвращается в бар одним чипом-счётчиком «Применено: N» (Chip Edit M), где N — число применённых параметров. Крестик чипа сбрасывает фильтр целиком; отдельной кнопки сброса в баре нет.

Использование

TableFilter отвечает за фильтрацию содержимого таблицы по нескольким параметрам сразу. Панель живёт в шапке таблицы: слева — кнопка вызова модалки, справа от неё — применённые параметры. В отличие от инлайн-поиска (одно поле над колонкой) фильтр собирает сложное условие из многих полей и сохраняет его набором.

Когда использовать
  • таблица фильтруется сразу по нескольким параметрам (тип, деск, продукт, период);
  • условие фильтра нужно показывать и снимать по частям;
  • частые наборы условий имеет смысл сохранять как пресеты.
Когда не использовать
  • фильтр по одному полю — достаточно инлайн-поиска или Select в шапке колонки;
  • переключение вьюх, а не сужение данных — это Tab или SegmentControl;
  • список без табличной структуры — фильтр-панель привязана к таблице.

Рекомендации

Бар остаётся читаемым, пока чипов немного; за пределом одного ряда работает сворачивание.

Так
Применённый фильтр сворачивается в один чип-счётчик «Применено: 3» рядом с кнопкой.

Бар занимает одну строку при любом числе параметров; состав фильтра смотрят в модалке.

Не так
Каждый параметр вынесен отдельным чипом («ТБ: ЦА, МБ», «Дески: RE, TMT»…) — бар переполняется и требует «+N» с аккордеоном.

Чиплист отдельных параметров — устаревшая модель бара, в новых экранах не используется.

Так
Сброс живёт на крестике чипа: есть чип — есть сброс, нет фильтра — в баре только кнопка «Фильтр».

Одно действие в одном месте, лишняя иконка-кнопка в баре не нужна.

Не так
Рядом с кнопкой «Фильтр» стоит отдельная кнопка сброса, дублирующая крестик чипа.

Два способа сбросить фильтр в двух сантиметрах друг от друга — шум, а не забота.

Анатомия

Всего два элемента: кнопка «Фильтр» и, при активном фильтре, чип-счётчик «Применено: N» справа от неё. Зазор между ними — 4px.

  • Кнопка «Фильтр» — Button Outline S с ведущей воронкой; открывает модалку
  • Чип «Применено: N» — Chip Edit M, N = число применённых параметров
  • Крестик чипа — сбрасывает все параметры фильтра разом
  • Шеврон пресетов — только когда есть сохранённые пресеты: ButtonGroup Split со списком названий

Варианты

Две оси конфигурации: состояние бара и значение счётчика в чипе.

Состояние бара

Фильтр не применён — в баре только кнопка «Фильтр». Применён — справа от кнопки чип «Применено: N».

С сохранёнными пресетами

Если у пользователя есть сохранённые пресеты, одиночная кнопка заменяется на ButtonGroup в варианте Split Button: слева «Фильтр» (открывает модалку), справа шеврон вниз — он открывает выпадающий список названий пресетов (ContextMenu). Выбор пункта применяет пресет сразу, минуя модалку. Нажмите на шеврон.

Цифра справа в пункте списка — число параметров в пресете. Пресетов нет — шеврона нет, в баре одиночная кнопка (пустой выпадающий список не показываем).

Чип «Применено»

Один чип на любое число параметров: меняется только N. Чип не переносится на второй ряд и не обрезается.

Чип — обычный компонент Chip (Edit · Fill · M) с крестиком; счётчик набирается цифрами с tabular-nums, чтобы ширина не дёргалась при смене N.

Размеры

Бар наследует размеры от вложенных компонентов: кнопка — Button Outline S, чип — Chip Edit M. Оба высотой 32px, поэтому высота бара — 32px.

Контент

Правила наполнения бара:

  • Формат чипа — «Применено: N», где N — число применённых параметров («Применено: 3»). Текст фиксирован, категории и значения в баре не перечисляются.
  • N считается по параметрам, не по значениям. Поле «ТБ: ЦА, МБ, СРБ» — один параметр, а не три.
  • Чип появляется только при N ≥ 1. Фильтр не применён — чипа нет, в баре одна кнопка.
  • Состав фильтра смотрят в модалке. Бар отвечает за факт и объём фильтрации, разбор по параметрам — в разделах модалки.
  • Кнопка «Фильтр» — существительное без счётчика; количество активных параметров передаёт чип, а не подпись кнопки.

Поведение

Открытие модалки, навигация по её разделам, счётчик применённых параметров, сброс и сохранённые пресеты.

Открытие модалки фильтра

Клик по «Фильтр» открывает модалку (Modal, ширина w6) с вертикальными табами-разделами слева и двухколоночной формой справа (одно поле — одна клетка, широкое поле занимает две; зазоры 16/20px). Обязательные части — Modal_Top (заголовок «Фильтр» + крестик) и Modal_Bottom: «Сохранить пресет» слева, «Очистить» и «Применить» справа. Высота модалки не фиксирована: растёт по контенту до 80vh, дальше прокручивается только Modal_Body, шапка и подвал закреплены и получают тень по .is-scrolled. «Применить» закрывает модалку и возвращает в бар чип «Применено: N».

Живой демо-мокап: вертикальные табы, поля, сохранённые пресеты и вложенные диалоги сохранения/удаления.

Разделы модалки — якорные ссылки

Вертикальные табы (Tab M, vertical) размещены вплотную к левой границе модалки: бокового паддинга у навигации нет, левый рельс и индикатор активного раздела совпадают с краем Modal_Body. Табы работают не как переключатель вьюх, а как якорные ссылки: Modal_Body содержит все разделы подряд и прокручивается сам (собственного скроллера у контентной области нет), клик по табу доводит тело до нужного раздела, а при прокрутке активным становится верхний видимый раздел (aria-current). Навигация — position: sticky, поэтому остаётся видимой при прокрутке. Бейдж в табе — число заполненных параметров раздела.

Навигация модалки: активный раздел — второй, у него заполнено 2 параметра.

Выбор пресета из бара

Когда есть сохранённые пресеты, шеврон ButtonGroup открывает список их названий под группой (зазор 6px, выравнивание по левому краю). Выбор пункта применяет пресет сразу — модалка не открывается, в бар приходит чип «Применено: N» по числу параметров пресета. Список закрывается кликом вне, Esc или выбором пункта; стрелки ↑/↓ водят по пунктам.

Живой демо-мокап: клик по шеврону открывает список, выбор пункта применяет пресет.

Скролл страницы под скримом

Пока модалка открыта, страница за скримом не прокручивается (правило Modal): на body ставится overflow: hidden, а ширина исчезнувшего скроллбара компенсируется правым паддингом, чтобы контент не дёргался. Содержимое страницы за скримом получает inert и aria-hidden, фокус заперт внутри модалки (focus trap по Tab/Shift+Tab), при открытии уходит на первое поле тела, при закрытии возвращается на элемент-инициатор. Замки считаются: вложенный диалог берёт свой, и скролл возвращается только после закрытия последнего слоя.

Слева — обычная страница со скроллом; справа — та же страница под скримом: затемнена, inert, скролл заперт.

Счётчик применённых параметров

После «Применить» бар получает один чип «Применено: N». N пересчитывается при каждом применении: параметр, у которого сняли все значения, из счёта уходит. N = 0 — чип не показывается.

Сброс фильтров

Крестик чипа сбрасывает фильтр целиком: параметры очищаются, таблица перезапрашивается, чип исчезает и в баре остаётся одна кнопка «Фильтр». Отдельной кнопки сброса рядом с «Фильтр» нет — сброс живёт только на крестике. Точечное снятие одного параметра делается в модалке.

Живой демо-мокап: нажмите крестик чипа.

Сохранённые пресеты

Текущий набор параметров сохраняется как именованный пресет (до 5 штук) кнопкой «Сохранить пресет» в подвале — она открывает вложенный диалог «Сохранить пресет» с одним полем (ширина w3, по объёму контента). Пресеты живут в разделе «Сохранённые пресеты»: применить, заменить (вложенный confirm при занятом имени) или удалить (вложенный confirm). Карточка пресета раскрывается шевроном-аккордеоном (IconButton Neutral S) и показывает таблицу «Параметр — значение» с составом набора. Пустой список показывает плейсхолдер.

Состояния

Интерактивные элементы бара наследуют состояния от Button и Chip; у самого бара есть отдельное состояние заблокированности.

Доступность

Бар — role="group" с aria-label="Фильтр таблицы". Кнопка «Фильтр» — aria-haspopup="dialog" и aria-expanded, связана с модалкой; шеврон пресетов — aria-haspopup="menu", aria-expanded и aria-label="Сохранённые пресеты", список — role="menu" с role="menuitem" на пунктах. Чип «Применено: N» фокусируем, его крестик озвучивается как «Сбросить все фильтры» и срабатывает по Backspace/Delete. Навигация модалки — <nav> с якорными ссылками и aria-current="true" на активном разделе (не role="tablist": разделы не переключаются, а прокручиваются). Каждое поле формы имеет свою метку (label[for]), двухколоночная сетка не меняет порядок табуляции.

Скрин-ридер

  • чип читается целиком: «Применено: 3»;
  • крестик чипа имеет aria-label="Сбросить все фильтры";
  • шеврон карточки пресета объявляет состояние через aria-expanded и связан с телом через aria-controls;
  • сброс фильтра объявляется, бар возвращается к одиночной кнопке «Фильтр».

Бэклог

Сверяясь с Material Design и практиками других ДС, документации бара недостаёт ряда кейсов. Все собраны на существующих токенах и компонентах.

  • Быстрые фильтры — ряд чипов-тоглов (Chip selected) перед кнопкой «Фильтр» для 2–3 самых частых условий без открытия модалки.
  • Пустой результат — подсказка «Ничего не найдено» с ссылкой «Сбросить фильтры» под таблицей, когда условие ничего не вернуло.
  • Счётчик результатов — опциональная подпись «Найдено: N» справа от бара.
  • Индикатор пресета — если применённые параметры совпадают с сохранённым пресетом, показывать его имя в чипе вместо «Применено: N».
  • Ховер-подсказка на чипе — тултип с перечнем применённых параметров, чтобы увидеть состав фильтра без открытия модалки.
  • Экраны-мокапы на старой модели — в pages/screens/04-Metrics.html и 07-CashFlow.html бар ещё собран чиплистом отдельных параметров с «+N»; перевести на чип «Применено: N» (legacy-правила в CSS помечены и оставлены только ради них).

Конструктор
