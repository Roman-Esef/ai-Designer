TableCell

Ячейка таблицы и ячейка шапки (TableHeader). Универсальный контейнер для любого типа контента строки: текст, дерево, чипы, контролы и редактируемые поля. Высота строки фиксирована и растёт только там, где ячейка сама разрешает перенос текста — плотностей строки нет.

Использование

TableCell — атом строки таблицы. Из ячеек разных типов собирается любая колонка: реестр сделок, финансовая сводка, дерево иерархии, редактируемая форма-таблица.

Варианты

Тип контента — настройка ячейки, а не отдельный вариант компонента (см. «Контент»). Собственный вариант у ячейки один — «Динамика».

Динамика (спарклайн)

Колонка тренда: форма изменения показателя за период в слоте .tc__spark (72×24px, ширина — через --tc-spark-w). Рисует его компонент Chart с type: 'spark' — без осей, легенды и тултипа: в строке таблицы читается только форма, точное значение стоит рядом отдельной колонкой. Тон auto красит линию по знаку изменения от первой точки к последней (--success / --error), заданный цвет серии — когда сравнивать надо не «лучше-хуже», а показатели между собой.

Полноразмерный график (с осями, легендой и тултипом) в ячейку не ставится: он ломает высоту строки 48px и требует наведения, которое конфликтует с тултипом усечения.

Правила по типам

  • Текст — по левому краю; по умолчанию усекается в одну строку (.tc__text--truncate) с Tooltip по наведению; если важно показать значение целиком — выключите усечение, ячейка перенесёт текст и вырастет по высоте.
  • Числа, суммы — включите настройку «Числовое значение»: выравнивание справа, табулярные цифры и разбивка разрядов (.tc--numbers). Форматировать через Intl.NumberFormat('ru-RU'), не вручную.
  • Иконки слева и справа — независимые опции. Левая (.tc__icon--lead) — тип или статус объекта, правая (.tc__icon) — признак значения (предупреждение, проверено). Обе 16px и идут сразу за текстом, а не у границы ячейки.
  • Вторая строка — опциональная мелкая строка под значением (.tc__subtext), доступна для любого типа ячейки с текстом: название + ИНН, сумма + валюта и т.п.
  • Prefix / Postfix — независимые настройки, включаются по отдельности в любом сочетании.
  • Пустое значение — прочерк «—» (.tc__empty, цвет inactive). Не оставляйте ячейку визуально пустой и не пишите «нет»/«null».
  • Действий в ячейке — максимум 2–3; больше — сворачивайте в кебаб-меню.

Поведение

Усечение текста, раскрытие дерева, сортировка и закрепление колонки, изменение ширины и порядка колонок, выбор и фокус строки, скрытые действия, редактируемые ячейки, навигация по сетке.

Усечение текста

Тултип с полным значением показывается только когда текст реально обрезан (scrollWidth > clientWidth), а не всегда у типа «Текст» — короткие значения тултип не получают. Проверка идёт и по hover, и по клавиатурному фокусу ячейки.

Дерево (TreeNode)

Твисти (шеврон) переключает aria-expanded и разворачивает/сворачивает дочерние строки — с поворотом глифа на 90°. Отступ строки считается от уровня вложенности (--tc-level × 20px), у листьев (без потомков) твисти не рендерится — вместо него зарезервировано пустое место той же ширины, чтобы значение не съезжало по горизонтали.

Живое демо: кликните по твисти — дочерние строки разворачиваются/сворачиваются.

Сортировка колонки

Опция включается для колонки в настройках шапки. Кнопка — IconButton neutral S; клик циклит состояние: не выбрана (arrow-up-down) → от меньшего к большему (arrow-narrow-up) → от большего к меньшему (arrow-narrow-down) → не выбрана. Неактивная стрелка — тон --secondary; по наведению на шапку и в выбранном состоянии — --secondary-dark. Одновременно активна максимум одна колонка таблицы; aria-sort синхронен иконке.

Изменение ширины колонки

Правая граница каждой ячейки шапки — ручка изменения ширины: зона захвата 9px без постоянной графики, по наведению проступает вертикальная линия. Во время перетаскивания через всю таблицу идёт линия-указатель в тоне --primary, а ширина колонки пересчитывается вживую. Ниже порога 96px колонка не сжимается — иначе подпись шапки и инструменты перестают помещаться. Ручка доступна с клавиатуры: фокус на ней и ← → меняют ширину шагом 16px. Свободное место справа забирает замыкающий разделитель, поэтому строка всегда занимает полную ширину таблицы.

Изменение ширины — не отключаемая опция: ручка .th__resize ставится последним ребёнком каждой .th (кроме разделителей) всегда. Поведение приходит из общего скрипта scripts/tbl-resize.js (делегирование на document, инициализация на странице не нужна); скрипт входит в scripts/ds.js, поэтому на собранном экране ресайз работает из коробки — подключать его отдельно не нужно.

Живое демо: тяните правую границу шапки — меняется ширина; тяните подпись — меняется порядок колонок.

Порядок колонок

Порядок меняется одним способом — перетаскиванием. Колонку берут за подпись шапки и переносят с зажатой кнопкой мыши: пока идёт перенос, вся колонка приглушается до 40%, а место вставки показывает вертикальная линия в тоне --primary. Перенос начинается после смещения на 4px, поэтому обычный клик по шапке остаётся кликом. Берут именно за подпись, а не за всю ячейку, — чтобы сортировка и закрепление оставались нажимаемыми. Разделители и закреплённые колонки из переноса исключаются; маркер не нужен — все остальные колонки переносятся автоматически.

Порядок колонок — базовое поведение, как и изменение ширины: работает из коробки, поведение приходит из общего скрипта scripts/tbl-reorder.js (входит в scripts/ds.js), инициализация на странице не нужна.

Кнопок и пунктов меню, дублирующих перенос, у колонки нет: порядок — прямая манипуляция, дополнительный орган управления на него не заводим.

Выбор и фокус строки

Интерактивное состояние живёт на строке: наведение, фокус и выбор красят все её ячейки, включая разделители по краям. Клик по любой ячейке переводит в фокус всю строку — её ячейки доступны для редактирования, показываются скрытые действия и иконки полей. Выбор чекбоксом даёт строке тон Selected; чекбокс в шапке — «выбрать все», при частичном выборе — промежуточное состояние (минус).

Живое демо: кликните по строке — фокус; отметьте чекбокс — Selected.

Скрытые действия

Скрытые действия — не тип контента, а настройка поверх любой ячейки (как EditMark). Кнопки появляются, когда курсор наводится на строку — в этот момент строка находится в состоянии Hover — либо когда строка в фокусе. На тач-устройствах показываются постоянно. Действий максимум 2–3, дальше — кебаб-меню.

Редактируемые ячейки

Ячейка не рисует собственное поле — внутрь ставится компонент Input размера S («Table Edit») со своими рамками, радиусами и состояниями. В покое поле сливается со строкой, по наведению проявляется рамка. Иконки действий (очистка, календарь, шеврон) показываются только когда строка или ячейка в фокусе — в покое ячейка показывает одно значение. Шеврон Autocomplete по клику раскрывает DropdownList; выбор опции подставляет значение.

Кликните в поле — иконки действий проявляются в фокусе.

Навигация по сетке

Внутри таблицы фокус перемещается между ячейками стрелками (grid-паттерн), а не табом по каждому интерактивному элементу — Tab уводит из таблицы целиком. Фокус-ячейка получает видимую обводку; если в ячейке несколько интерактивных элементов (например, кнопка + чип), первую активацию Enter/Space получает первый из них.

Кликните по ячейке и используйте стрелки — фокус переходит между ячейками сетки; Tab уводит из таблицы.

Состояния

Интерактивные состояния (Hover, Focus, Selected) — свойство строки: они красят все её ячейки сразу, включая разделители. Служебные (Error, Empty, Skeleton, EditMark, фон колонки) — свойство отдельной ячейки. Состояния Disabled у таблицы нет.

Corner cases

  • Фон + состояние комбинируются: hover/focus у accent- и pinned-колонок имеют собственные тона (--bgtable-accent-hover, --bgtable-pinned-hover).
  • EditMark — угловой маркер в правом верхнем углу ячейки, виден до сохранения/сброса правки.
  • Скрытые действия (.tc__hidden) появляются только по наведению/фокусу строки; сочетаются с усечённым текстом и Tooltip в той же ячейке.
  • Состояния Disabled у таблицы нет — строка или ячейка не бывают недоступными; недоступность выражается отсутствием действия, а не серым текстом.
  • Состояние живёт на строке, не на ячейке: hover / focus / selected красят все ячейки строки, включая разделители по краям. Ячейка-разделитель принимает только эти состояния — EditMark, Skeleton и Error-текста у неё не бывает.

Доступность

  • Семантика таблицы — использовать нативные <table>/<th>/<td> либо ARIA-роли role="grid"/"columnheader"/"gridcell". Классы .tc/.th — только оформление.
  • Сортировка — на ячейке шапки aria-sort="ascending|descending|none"; кнопка сортировки имеет aria-label с текущим направлением.
  • Ширина колонки — ручка role="separator" + aria-orientation="vertical", в фокусе управляется стрелками ← →; перетаскивание мышью не должно быть единственным способом изменить ширину.
  • Закрепление колонки — кнопка-переключатель: aria-pressed + aria-label («Закрепить / Открепить колонку»). Появление по hover не должно быть единственным способом добраться до неё — кнопка доступна с клавиатуры (:focus-within шапки).
  • Выбор строки — реальный чекбокс; состояние строки — aria-selected. Заголовочный чекбокс = «выбрать все».
  • Клавиатура — перемещение по ячейкам стрелками (grid pattern), фокус-ячейка получает видимую обводку (:focus-visible, inset 2px primary).
  • Усечённый текст — полное значение доступно через Tooltip (hover и focus) и title.
  • TreeNode — твисти: aria-expanded; строки дерева — role="row" + aria-level.
  • Иконка после значения и кнопки без текста — обязателен aria-label/title.
  • Skeleton — контейнер aria-busy="true"; шиммер отключается при prefers-reduced-motion.
  • Контраст — фоны состояний и текст соответствуют WCAG AA; статус не передаётся только цветом (дублируется текстом/иконкой).

Поведение (framework-agnostic)

// 1. Состояние — свойство СТРОКИ, не ячейки // hover / focus / selected ставятся на строку и красят все её ячейки, // включая структурные разделители по краям. Состояния disabled нет. // Клик по любой ячейке ⇢ фокус всей строки: её ячейки доступны для // редактирования, показаны скрытые действия и иконки полей. row.classList.toggle('is-hover' /* .tbl__row--hover */, hovered) // 2. Усечение + Tooltip (по умолчанию включено) // Значение в одну строку (.tc__text--truncate, flex: 0 1 auto — постфикс // и иконка идут сразу за текстом). Если scrollWidth > clientWidth — // показать Tooltip с полным текстом по hover/focus. Усечение выключено ⇢ // текст переносится (.tc--wrap), ячейка растёт, Tooltip не нужен. if (truncateEnabled && cellText.scrollWidth > cellText.clientWidth) attachTooltip(cellText, full) // 3. Числовые колонки // .tc--numbers = выравнивание справа + tabular-nums; разряды форматировать // через Intl.NumberFormat('ru-RU'), не вручную. Отдельный .tc--right не нужен. // 4. Сортировка (настройка колонки в шапке) // Клик ⇢ цикл none → ascending → descending → none. // Глифы: arrow-up-down → arrow-narrow-up → arrow-narrow-down. // Кнопка = IconButton neutral S. Цвет: покой --secondary, // hover шапки и активная сортировка --secondary-dark. aria-sort синхронен. // Активна максимум одна колонка таблицы. // 5. Закрепление колонки (настройка колонки в шапке) // Свойство КОЛОНКИ: фон Pinned у шапки и всех ячеек под ней + sticky при // горизонтальном скролле. Глиф pin (по hover шапки) → pin-filled // (закреплено, видна всегда, --secondary-dark), aria-pressed. // Нет сортировки ⇢ закрепление занимает её место. // 6. Выбор строк // Чекбокс — компонент Checkbox без текстового слота (.cb--no-content). // Заголовочный = выбрать все / промежуточное состояние при частичном выборе. // Выбор строки ⇢ тон Selected на всей строке. // 7. Дерево (TreeNode) // Отступ = --tc-level × 20px. Твисти toggle aria-expanded и раскрывает // дочерние строки под собой. Лист — .tc__twisty--leaf (место зарезервировано). // 8. Клавиатура (grid pattern) // Стрелки — перемещение фокуса по ячейкам; Enter/F2 — вход в редактирование // input-ячейки; Esc — отмена. Фокус-ячейка: :focus-visible inset outline. // 9. Скрытые действия — настройка поверх ячейки (как EditMark) // .tc__hidden видимы при hover/focus СТРОКИ; на тач-устройствах — всегда. // 10. Редактируемые ячейки // Внутрь ячейки ставится компонент Input размера S — своё поле ячейка не рисует. // В покое поле без рамки и фона; hover строки проявляет рамку; фокус даёт // рамку --primary 2px. Иконки действий (очистка, календарь, шеврон) видны // только в фокусе строки/ячейки, размер 16px, тон --secondary. // Autocomplete: шеврон открывает DropdownList, выбор подставляет значение. // 11. EditMark // После изменения значения ставить .tc--edited (правый верхний угол) до // сохранения/сброса. Ошибку валидации — .tc--error (+ tooltip с причиной). // 12. Ширина колонки // Ручка = правая граница ячейки шапки: зона захвата 9px, графика только // по hover/focus. Drag ⇢ width = max(96, стартовая + dx), пересчёт вживую, // линия-указатель через всю таблицу. Клавиатура: focus + ← → шагом 16px. // Свободное место справа забирает замыкающий разделитель // (grid: 8px … minmax(8px, 1fr)), поэтому строка всегда во всю ширину. // 13. Порядок колонок — только перетаскивание // Перенос за ПОДПИСЬ шапки (не за всю ячейку — сортировка и закрепление // должны остаться кликабельными). Порог старта 4px, чтобы клик оставался // кликом. Пока идёт перенос: колонка приглушена до 40%, место вставки — // вертикальная линия на ближайшей границе (по центрам колонок). // Закреплённые колонки из переноса исключаются. Кнопок и пунктов меню, // дублирующих перенос, у колонки нет. // 14. Separator // Структурная пустая ячейка 8px, первая и последняя в каждой строке. // Принимает только состояния строки и фон колонки: EditMark, Skeleton и // Error-текста у неё быть не может. Пользователем как тип не выбирается.
