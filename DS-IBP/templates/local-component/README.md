# Шаблон локального компонента

Папка-заготовка для локального компонента продукта. Правила, по которым она заполняется, —
на странице ДС «Локальные компоненты» (`pages/patterns/LocalComponents.html`).

## Как начать

1. Скопировать всю папку в проект продукта: `kit/components/<Имя>/`.
2. Переименовать файлы `Component.*` в `<Имя>.*` (одно имя, PascalCase, без пробелов).
3. Заполнить `<Имя>.md` — сначала паспорт, потом разметку. Обязательные поля перечислены в шапке файла.
4. В `<Имя>.doc.html` и `<Имя>.css` заменить префикс класса `lc-component` на `lc-<имя>`.
5. Проверить путь до ДС в `<Имя>.doc.html`: строка `<link rel="stylesheet" href="…/ds.css">`.

## Что менять в первую очередь

| Порядок | Файл | Что |
|---|---|---|
| 1 | `<Имя>.md` | Паспорт: category, purpose, description, fields, sources, required, roles, states, opens |
| 2 | `fixtures.json` | Демо-данные по состояниям — витрина работает от них |
| 3 | `<Имя>.html` | Разметка: только компоненты ДС, внутри — слоты полей |
| 4 | `<Имя>.css` | Внутренняя раскладка и перестроение по своей ширине. Цвета и шрифты — токены ДС |
| 5 | `<Имя>.doc.html` | Витрина: все состояния рядом. Состояния, которого нет в витрине, не существует |
| 6 | `baseline.png` | Снимок базового состояния из витрины |
| 7 | `CHANGELOG.md` | Первая строка журнала: создание компонента |

## Категория

Поле `category` обязательно: по нему компонент попадает в группу витрины кита и в её левую
навигацию. Категория одна. Список категорий задаёт проект, не ДС; если компонент просится сразу
в две — это либо два компонента, либо один переиспользуемый.

## Версия правил

В шапке паспорта есть поле `rulesVersion` — версия страницы правил ДС, по которой компонент заполнен.
Оно не декоративное: когда правила в ДС меняются, компонент с прежней версией попадает в список
расхождений, и работа становится конечным списком вместо обязанности всё помнить.

При переносе шаблона в проект поле уже заполнено текущей версией правил — менять его нужно только
тогда, когда компонент действительно приведён к новым правилам.
