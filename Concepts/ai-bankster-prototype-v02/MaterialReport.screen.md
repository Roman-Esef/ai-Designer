# Материал с идеями — бриф перед встречей

## 1. Назначение

Готовый материал AI Pitcher в том виде, в каком его получает пользователь:
бриф перед встречей с клиентом. Открывается превью в панели просмотра на экране
«Новый отчёт» (`RequestThread.html`) — во фрейме, по кнопке «Просмотр» на
карточке материала и из уведомления о готовности. Отдельной навигации у
страницы нет: это документ, а не экран раздела.

## 2. Структура

| Блок | Содержание |
|---|---|
| Обложка | надзаголовок «Бриф перед встречей · ДИД», название компании, описание бизнеса, строка параметров материала, пять ключевых показателей |
| Executive Summary | абзац с выводом о компании |
| Финансы и рынок | Chart `grouped` L — выручка и чистая прибыль 2021–2025; Chart `area` M — учётная цена золота ЦБ; Chart `hbar` M — долговая нагрузка против медианы и лидеров отрасли |
| Производство и владение | Chart `bar` M — добыча золота с прогнозом под ЗИФ-3 (`forecastFrom`); Chart `donut` M — структура владения |
| Возможности ДИД | пять карточек направлений; оценка — Chip `--success` / `--warning` / `--error`, приоритет — Chip `--info` |
| Инсайты | нумерованный список из трёх выводов |
| Ключевые риски | три риска с уровнем (Chip `--error` / `--warning`) и описанием влияния на сделку |
| Позиция на встрече | выделенный блок с рекомендацией |
| Подвал | источники чипами, строка о подготовке материала |

Валюта — кодом RUB. Числа на графиках форматирует рантайм Chart (ru-RU,
компактный формат на осях).

## 3. Поведение

Графики — штатная интерактивность Chart: тултипы, выключение серии кликом по
легенде, подсветка серии при наведении.

**«Доработать в чате»** — только когда материал открыт в панели просмотра
экрана «Новый отчёт» (страница во фрейме):

| Триггер | Результат |
|---|---|
| Выделение текста в листе материала | над выделением всплывает Button Accent S «Доработать в чате» |
| Клик по всплывающей кнопке | фрагмент уходит в поле ввода экрана «Новый отчёт» чипом с началом текста; выделение снимается |
| Выделение задевает графики | вместе с текстом уходят теги графиков «График «название»», подписи осей в текст не попадают |
| Наведение на карточку графика | в углу карточки появляется Button Outline XS «Доработать в чате» |
| Клик по кнопке графика | график уходит в поле ввода тегом, карточка коротко подсвечивается |

Фрагмент передаётся экрану сообщением `postMessage` (`source: 'ai-pitcher-material'`,
`type: 'context'`, `items: [{ kind: 'text' | 'chart', text, title, section }]`):
прямой доступ к документу фрейма закрыт при открытии файла двойным кликом.
Экран принимает сообщение только от своего фрейма. В чипе текст раскрывается
целиком по клику; при отправке чипы попадают в сообщение пользователя.

## 4. Открытые вопросы и допущения

| № | Вопрос / допущение | Статус |
|---|---|---|
| 1 | Ряды графиков — демо-данные прототипа, согласованные с цифрами материала (выручка и прибыль 2025, рентабельность, долговая нагрузка, добыча 2023, цена золота на 27.01.2026). Остальные точки — оценка для правдоподобного вида | **допущение** |
| 2 | Обложка, карточки направлений, список инсайтов, блок рисков и блок позиции — локальные элементы на токенах ДС: компонента «документ-материал» в ДС нет | **допущение**, кандидат в компонент |
| 3 | Доли владения показаны обезличенно («Бенефициар 1–3») — в материале указаны только доли | **допущение** |
| 4 | Реальный материал формирует агентная система файлом PDF или Word; страница показывает, как такой файл выглядит в превью | **допущение** |
| 5 | Страница — документ, который показывается во фрейме панели просмотра, а не экран раздела: каркаса Layout (меню, крошки, шапка страницы) у неё нет. Сенсор даёт Б5 «каркас» и Б6 «h1 в .phead__title» — отклонение осознанное, в сенсоре нет типа «документ-превью» | **вопрос владельцу ДС**: завести исключение для страниц-документов |
